# 史莱姆大暴走 · Slime Rampage

俯视角动作肉鸽（Roguelite）割草游戏：**反套路 RPG 剧情**——你不再是勇者，而是一只位于食物链最底端的史莱姆。骑士、魔法师、弓箭手组成的勇者大军源源不断涌入地下城，你需要吞噬一切来进化自保。
所有视觉元素均由 HTML5 Canvas 纯代码程序化绘制（数学图形 + 渐变），零外部图片资源。

> `0.2.0` 定位为桌面浏览器预览版：新增三槽档案、局域网账号/公共榜、无尽深层抉择、远征巢心守卫与地图功能地形。当前推荐使用最新版 Chrome 或 Edge；移动端触控尚未适配。

## 操作

| 操作 | 按键 |
| --- | --- |
| 移动 | `WASD` / 方向键 |
| 冲刺 | `Space` / `Shift` |
| 吸收元素核心 | `E` |
| 暂停 / 继续 | `Esc` |

## 运行

需要 Node.js `22.16.0+`。

```bash
npm ci
npm run dev     # 开发（Vite HMR）
npm test        # 全量逻辑与无头引擎回归
npm run build   # 生产构建
npm run preview # 本地预览 dist
npm run lan     # 构建并启动局域网主机
```

单机档案保存在当前站点域名对应的 `localStorage` 中；更换域名或清理浏览器站点数据会产生一份新档案目录。局域网主机数据默认保存在项目根目录 `data/`，可通过 `SLIME_DATA_DIR` 调整。

### 局域网主机

```bash
npm run lan    # 构建并启动局域网主机（默认端口 4173）
```

启动后控制台会打印本机与局域网访问地址，其他设备在浏览器打开同一地址即可加入：局域网账号注册/登录、远程三槽档案、全员排行榜与结算同步均由主机提供；不登录也可直接游玩和查看榜单。

**Windows 防火墙**：首次启动会弹出授权框，请选择"允许访问"。若误点取消，其他设备将无法连接，可在管理员终端执行
`netsh advfirewall firewall add rule name="SlimeRampage-LAN" dir=in action=allow protocol=TCP localport=4173`
放行（端口以 `SLIME_PORT` 为准）。

## 发布

- 推送到 `main` 后，`CI` 工作流会执行干净安装、全量测试、生产构建，并保存 `dist` 构建产物。
- 推送 `v*` 标签（例如 `v0.2.0`）或手动运行 `Deploy GitHub Pages` 工作流，会重新验证并部署 GitHub Pages。
- 首次部署前，需要在仓库 Settings → Pages 中把 Source 设置为 **GitHub Actions**。
- 正式打标签前仍需在桌面 Chrome / Edge 各完成一局人工试玩，检查音频、键盘、暂停和存档。

## 架构红线：Vue UI 层 ⇆ Canvas 游戏层严格解耦

| 方向 | 通道 | 频率 |
| --- | --- | --- |
| UI → 引擎 | 显式方法调用（`start / stop / pause / resume / destroy`） | 事件驱动 |
| 引擎 → UI | `onStats` 回调（引擎内部节流到 ~2Hz）；`onLevelUp` 升级事件 | 低频 / 事件驱动 |

**禁止事项（性能红线）：**

1. 每帧坐标、碰撞、渲染数据**严禁**进入 Vue 响应式系统（`ref` / `reactive` /
   `watch`）——`GameEngine` 与全部实体为原生 JS 对象，主循环 `update(dt) → render()`
   不触碰任何响应式依赖。
2. Vue 组件中引擎句柄用普通变量持有（见 `GameCanvas.vue`），不用 `ref` 包装；
   只有 HUD 显示用的低频统计（FPS / 坐标）经节流回调进入响应式系统。
3. 渲染热路径零分配：渐变对象构建一次复用、输入向量缓存复用、
   deltaTime 首帧归零、后台恢复上限 `MAX_DT = 0.05s` 防物理爆炸。
