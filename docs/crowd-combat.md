# 主战场收割节奏与反馈

本轮只扩展 Arena 主战场：战獒奔潮、讨伐小队破阵、重击反馈、暴食饱食酸浪和结算高光。地图爆炸机关、尸体碰撞、动态地表污迹及全技能伤害占比留待后续验证。

## 遭遇节奏

`CrowdDirector` 复用 `EnemyManager` 的普通刷怪时隙与人口上限。有效波次至少为 3 时，累计 6 秒可用窗口后首次进入奔潮；之后在每场遭遇结束后等待 38 秒，交替尝试小队与奔潮。远征强度仍按章节计算。

首领存活/待入场、首领登场与战后喘息、世界事件、守巢、章节进度超过 70%、章间整备和限时最后 30 秒均不启动遭遇。已有遭遇在这些状态出现时结束；所属小队的恐惧、易伤及额外盾同时清理。遭遇期间世界事件等待，不和讨伐队叠加。换章清空遭遇与刷怪配额欠账。

- **战獒奔潮**：持续 15 秒；每个常规增援时隙替换成两只普通战獒，不生成精英或词缀。生命降到同波普通战獒的 35%（最低 1），经验各为 35%（向下取整、最低 1），接触伤害 0.35，速度提高 10% 且遵守难度速度上限。仍受普通人口软上限和 300 硬上限约束。

奔潮接触伤害经过玩家减伤时保留小数，防止被普通攻击的最低 1 点取整规则反向放大；普通攻击的既有规则保持不变。
- **讨伐小队**：三名盾骑士、两名弓手、一名牧师旗手；从有足够空间的方向两排进场，靠近后沿用原有职业 AI。盾骑士各有一次吸收盾。六名成员预支六个后续常规刷怪时隙，不额外叠加长期人口与经验预算；小队关系最多维持 26 秒。
- **破阵**：旗手被击杀、DOT 击杀或吞噬均触发一次；仅所属小队破盾、逃离玩家并停止攻击 2 秒，期间承伤 ×1.35。不扩散至散兵或 Boss，不产生伤害或连锁破阵。

## 重击反馈

`CombatFeedback` 使用独立表现时钟，暂停的是整套战斗模拟：生命判定、投射物、冷却、无敌与 Boss 预警共享战斗时间，画面与 HUD 仍绘制，技能输入保留到下一次战斗更新。

重咬和影袭按一次施放合并命中；融合爆发按一次范围结算计数。重咬/影袭至少一次实际伤害提供 16ms 短顿帧与 2.5px 定向镜头回弹；至少五目标实际受伤或三次击杀升级为 35ms、5px。融合爆发仅在至少五目标实际受伤时触发。全局反馈间隔分别为 0.35/0.65 秒；护盾全吸收、挥空不触发。镜头偏移不移动玩家，不消耗战斗随机数。

## 暴食饱食酸浪

猎食点上限 2、正常/首领充能进度满仓冻结、主动捕食不返充均保留。

满仓后每正常吞噬三只非精英血肉杂兵，预约一次半径 90px 的酸浪；在武器更新末尾兑现，同帧批量吞噬合并，触发至少间隔 2 秒，间隔内不储存下一次酸浪。每次最多影响八只普通敌人，每目标伤害为基础攻击 × 等级乘区 ×0.45，不使用吞噬滚雪球乘区、不扩大吞噬线、不触发吞噬、不造成硬直、不返充猎食点。既有击杀奖励仍经过唯一结算点。

主动重咬仍为普通目标基础 ×4、首领 ×6，并拥有路线与成长收益。酸浪作为有限补偿；消耗猎食点清掉未兑现溢出，不能作为第三点储备。首领战期间停用且不累计；精英和首领不受酸浪伤害。换章、新局和死亡清掉临时状态。

## 统计与验收

结算增加最高连续击杀（间隔不超过 1.8 秒，包含吞噬）、重击最高收割（重咬含本次余波、影袭本体、单次融合范围爆发）、小队破阵、奔潮击杀与酸浪次数。字段位于 `weaponSystem.stats`，章间续玩保留累计值，新局清零。`highlights` 是独立结算快照。

诊断字段 `damageDealt` / `bossDamageDealt` 记录实际生命损失，排除护盾吸收和过量伤害；`overflowDamage`、`heavyBites` 用于复核溢出贡献和主动使用情况。当前不展示全技能伤害占比，避免不完整来源归因误导构筑判断。

- `npm run test:crowd`：真实引擎专项，覆盖刷怪预算、软上限、来源归属、吞噬破阵、首领隔离、顿帧输入与共享时钟、伤害统计、续玩及重开。
- `npm run test:crowd:browser`：独立内存数据库和临时生产构建，验证桌面与 390px 窄屏的遭遇、酸浪、HUD 与结算；截图和 300 敌人帧耗时样本写入 `.workbuddy/crowd-browser/`。本机无头浏览器的帧耗时仅供回归参考，不能代表真实设备 FPS。

数值是首轮试玩起点。后续应对照相同构筑与难度检查普通敌人的清理耗时、主动释放频率、进入首领战的等级及首领击杀耗时，并通过人工试玩判断压力与收割是否形成可感知的起伏。
