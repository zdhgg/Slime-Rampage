# 暴食近战重构

暴食从开局使用自动咬击，主专精仍在 Lv.5 自动觉醒。技能 ID 保留，角色与档案选择方式不变。

## 战斗规则

| 动作 | 范围与时序 | 结算 |
| --- | --- | --- |
| 普攻 | 身体边缘外延 48px，110°，0.12 秒前摇 + 0.045 秒出手，咬合帧结算；基础间隔 0.85 秒 | 1.35 倍攻击，可暴击；残血或咬杀的血肉目标直接吞噬 |
| F 暴食重咬 | 外延 68px，140°，0.16 秒前摇 + 0.06 秒出手；消耗 1 猎食点 | 4 倍攻击，首领 6 倍；同样衔接吞噬，首领不可吞噬 |
| 捕食护甲 | 吞噬或重咬命中首领触发；持续 1.2 秒，每 2.5 秒至多获得一次 | 一层抵挡 1 点伤害，不能叠加；重击剩余伤害正常结算 |
| 吞噬恢复 | 基因、共鸣与牧师吞噬收益共用 4 秒间隔 | 同次吞噬只恢复一次；普通再生技能不受影响 |

普攻保留攻击就绪直到近处存在目标。普攻/F 从起手锁定方向，身体和嘴部跟随同一方向，目标可以在前摇或出手期间绕背、离开范围。范围计算考虑敌人的身体半径，地面淡色提示与伤害判定使用同一扇形（提示外延多 1px）。F 起手前无目标时不扣点；F 可以替换普通前摇，但不会打断已经出手的咬击。

攻击周期从起手计算，不额外叠加动作等待。高攻速下普攻前摇/出手缩短至基础时长的 55%–100%，收势优先压缩并允许下一次普攻接续。普通前摇最低 0.066 秒。F 维持完整动作时长。

## 攻击表现

- 前摇：身体沿攻击方向压缩、略微后收，前方嘴部张开。出手：身体前探拉伸，上下颌向前伸出并咬合。身体位移仅为绘制偏移，不改变玩家位置或冲刺方向。
- 普攻主效果为连续的嘴部/牙齿动作，移除原来的牙弧与强扇面描边；保留轻薄覆盖和两侧短边提示范围。F 加大身体动作与牙齿，并加前向扑食拖痕。
- 命中：敌人接触位置出现小白闪和黏液碎屑，普通敌人短促抖动；重咬强化闪光与咬合音。咬空只有轻咬合声，不播放命中音、不生成命中粒子。
- 吞食：敌人缩向嘴部，碎屑向嘴回收，身体短促膨胀；猎食点增加时身体边缘发亮。基础吞食移除敌人位置上的扩散绿环，护甲提示收在身体边缘；有实际范围伤害的胃酸爆发继续显示自身范围。
- 咬合残像保留真实结算位置，嘴部快速回收，身体回弹；死亡、重开或换角色清除动作与残留反馈。

正常吞噬基础每 5 次、近战普攻命中首领基础每 10 次获得 1 猎食点，上限 2。护盾吸收的命中不充能。F、冲撞和酸爆命中首领不充能；F 及其酸爆触发的自动吞噬不返充。满仓时两种进度冻结。首领战 HUD 展示首领命中进度。

所有伤害经过敌人已有的护盾、易伤与死亡结算。捕食在扣血后、死亡前分流，吞噬与击杀不能重复奖励；魔像和怨灵仍不可吞噬。

## 专精成长

- 深渊胃囊：提高吞噬线、吸附范围和两种充能效率，移除攻击降低。
- 硬化甲壳：每级生命 +1，护甲持续时间依次为 1.6 / 2.0 / 2.4 秒。
- 腐蚀重碾：保留冲刺冷却与撞击伤害成长，撞击可衔接吞噬；冲刺结束恢复咬击就绪。
- 胃酸迸发：吞噬或重咬命中首领触发 100 / 110px 近身爆发；伤害为攻击的 1 / 1.35 倍，减速普通敌人 0.7 秒。密集触发合并，每 0.4 秒最多一次，不生成飞弹，也不递归吞噬。
- 荒古吞噬领主：体型 +30%，咬击外延范围与伤害 +25%，重咬和撞击可以吞噬命中后半血以下的血肉敌人，基础首领充能门槛降为 8。

## 验证

- `npm test`：全量测试通过。
- `node verify-glutton.mjs`：21 组机制测试，覆盖扇形边界、过量致命伤吞噬、奖励去重、护盾和敌族限制、资源来源、护甲/恢复间隔、中途阵亡与重开清理；新增前摇/出手/咬合时序、方向锁定与咬空、范围可视一致性、高攻速周期和反馈清理。
- `node verify-glutton-regression.mjs`：6 组固定种子的 180 秒敌潮及 9 组无杂兵首领场景。全部场景能够自然充能并使用 F；三档构筑实际输出效率随成长提高。
- 首领测试使用真实移动、攻击与阶段机制，仅关闭杂兵来源。简单走位机器人在 Lv.1 和 Lv.8 法师首领场景阵亡，Lv.14 三种首领均通关。这些测试验证机制与成长，不代表真人胜率。
- `npm run build`：通过；保留项目现有的大包体提示。
- 后台浏览器验证角色选择、战斗 HUD、咬击前摇与命中、F 吞噬、护甲及首领充能显示，无未处理异常。最新截图与日志位于 `.workbuddy/glutton-bite-readability/`；`bite-sequence.png` 为真实实体绘制的八格动作分镜，包含绕背咬空及多方向攻击。
