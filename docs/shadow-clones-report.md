# 暗影闪避率与暴击分身实施报告

日期：2026-10-07。用户批准后实施，代码与说明已写入当前工作区；没有提交或覆盖工作区中既有的其他改动。

## F 留身与概率成长（最新调整）

- 新增暗影专属 T1 单级无前置「影袭留身」：F 成功施放即在起点生成分身，可空放自保。满额时最短寿命分身回到起点并刷新，保留攻击冷却；该分身不参与当次夹击。
- F 留影继承分身成长、可诱敌挡弹，不占用暴击生影的概率判定或触发间隔；命中暴击仍可额外生影，但共享数量上限。
- 影生共鸣改为三级，每级 +10 个百分点：60% → 70% → 80% → 90%。下文首轮记录中的 100% 属于旧参数。
- 专项检查扩展至 35 组。最新完整回归日志：`../.workbuddy/shadow-clones/f-origin-test.log`。历史清怪与生存对照未重新测量。
- 本轮全部 32 个测试脚本与生产构建通过；构建仍有既有主包体积提醒。

## 远程围攻补强（后续批准）

- 普通法师、弓手会瞄准附近可见分身；分身在原追击范围内优先切远程。近战、Boss 和守巢目标优先级保留。
- 分身可拦截普通弹幕，每发消耗 0.5 秒寿命，耗尽即停止；按轨迹首次碰撞结算，避免高速弹穿透或身后分身隔空挡弹。Boss 弹幕与范围技能保持原规则。
- 闪避成功后虚化 0.2 秒，期间免疫敌方攻击、不重复判定、不延长保护；不免除事件成本。
- 角色介绍与技能说明同步更新。专用验证扩展至 31 组，包含 20 发同帧弹幕、寿命耗尽、碰撞顺序、实际射击方向及 Boss 来源隔离。
- 本次 `npm test` 全部 32 个脚本通过，生产构建成功；构建仍有现有的主包超过 500kB 提醒。本次未重新进行浏览器截图或真人平衡测试。
- 下文性能、胜率与清怪对照属于首轮实施记录，不代表本次补强后的测量结果。本次完整回归日志：`../.workbuddy/shadow-clones/anti-ranged-test.log`。

## 交付

- 被动闪避：基础 15%，技能最高 30%，与秘典合计上限 40%。
- 本体有效暴击后 60% 概率生成分身，技能可提升至 100%；基础 2 个、4 秒、40% 非暴击攻击力。
- 独立升级分身概率、强度、数量、持续时间；最高 4 个、7 秒、85% 攻击力。
- F 保留定向穿行与首击必暴，冷却 6 秒，指挥已有分身集中夹击；新生成分身不追加当次夹击。
- 终极分身贯穿与十字夹击；本体、纯视觉残影、真实分身有明确区别。
- 修复暴击/暴伤升级覆盖；闪避不触发实际受击奖励、怨灵命中吸血或重复伤害判定。
- 状态栏、角色介绍、升级卡、秘典说明与 README 同步。
- 暗影角色变体独立，原生黏液保留刺客玩法；公共回归覆盖其他角色、跑酷、塔防。

参数沿用批准方案起始值，详细规则见 [暗影战斗说明](shadow-melee.md)。

## 同条件对照

保存了实施前的源码快照，使用同一控制器、种子集合、普通难度及合法升级预算对照。敌潮两组各 40 个种子，最多运行 120 秒，第一次阵亡停止；统计为机器人实验，不代表真人胜率。新旧版本使用各自可用的角色技能优先级，新增随机判定会改变后续随机序列，因此这不是逐次攻击完全配对的因果实验。

| 敌潮控制方式 | 旧版 | 新版 | 变化 |
| --- | --- | --- | --- |
| 使用 F：清怪数/分钟 | 25.27 | 43.94 | +73.9% |
| 使用 F：平均首条生命存活 | 28.02 秒 | 31.37 秒 | +12.0% |
| 不使用 F：清怪数/分钟 | 20.11 | 25.27 | +25.7% |
| 不使用 F：平均首条生命存活 | 29.99 秒 | 24.10 秒 | −19.6% |

使用 F 时，首次出现分身平均约 7.82 秒；不使用 F 时，有成功召唤的样本平均约 11.16 秒。统计包含走位、起手、刺空和升级，没有隐藏的非暴击召唤保底。

需要保留的取舍：新版用闪避率和分身替代原技能的大量移速成长。不使用 F 的简单机器人虽然杀怪更快，存活时间仍下降约 20%；当前数据不支持“所有操作方式的生存均提升”。实际游玩仍应利用影袭脱离和集火。原定前期 +15%–25% 为调优目标；使用 F 的清怪增幅超过该范围，结合首领结果及其他角色参照，本轮未再次上调伤害。

无杂兵首领每档包含骑士、法师、弓手各 3 个种子，均使用 189 HP 固定对照目标：

| 构筑 | 旧版击败数 | 新版击败数 |
| --- | --- | --- |
| Lv.1，无升级 | 6/9 | 6/9 |
| Lv.8，7 点升级 | 6/9 | 8/9 |
| Lv.14，13 点升级 | 9/9 | 9/9 |

Lv.14 全部胜出样本的平均击杀时间从 14.24 秒降至 13.15 秒，约缩短 7.7%。Lv.1 法师场景仍可能阵亡，完整构筑没有出现伤害异常倍增。

另对暴食、弹射、元素各做了 3 个种子的角色适配控制参照；样本小且打法差异明显，保留原始记录，不据此给出角色胜率排名。

原始数据：[旧版](../.workbuddy/shadow-clones/comparison-old.json)、[新版及其他角色](../.workbuddy/shadow-clones/comparison-new.json)、[可复跑脚本](../.workbuddy/shadow-clones/compare.mjs)。

Lv.8、7 次合法升级、30 秒单目标持续输出，40 个种子。每组把一个通用生命点换成对应分身升级，比较分身实际造成的伤害；本体攻击与等级一致。

| 单点投资 | 分身平均伤害 | 相对基线 |
| --- | --- | --- |
| 基线 | 54.67 | — |
| 生成概率 | 63.37 | +15.9% |
| 分身强度 | 69.58 | +27.3% |
| 持续时间 | 62.16 | +13.7% |

四项均产生了独立的实际输出收益。概率、持续时间与数量受场上分身占用情况影响，不保证每档构筑都线性增长。

## 压力与画面

300 个敌人、4 个分身，后台浏览器按真实逐帧更新后再渲染；预热 20 帧，采样 100 帧。记录的是 CPU 更新与 Canvas 提交耗时，不是完整 GPU 帧率：

| 场景 | 平均更新+渲染 | P95 |
| --- | --- | --- |
| 同场景无分身 | 2.01ms | 3.40ms |
| 同场景 4 分身 | 3.22ms | 4.20ms |

分身持有目标，失去目标后按间隔重选；数量有上限。性能数据来自当前机器的后台 Edge，不代表所有手机设备。
