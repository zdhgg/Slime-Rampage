# 塔防难度与要素展开改进方案

日期：2026-10-02。状态：**用户已批准，实施及自动验收完成。** 下文保留批准时的设计依据；最终参数、验证结果和真人试玩待确认项见 [实施报告](tower-defense-difficulty-implementation.md)。

建议批准的范围：先统一不同屏幕下的战斗规则，再调整关内波次节奏、关卡衔接和部分机制的教学顺序；先完成前 20 关试调，再推广至全部 99 关。保留第一关逐步扩建的目标。

批准前的审计仅新增工具、数据和文档，没有修改游戏规则、建筑属性、关卡配置或存档。原始依据见 [审计报告](tower-defense-difficulty-audit.md)、[99 关逐关表](tower-defense-audit/stages.csv)和 [965 波明细](tower-defense-audit/waves.csv)。这些文件保留为修改前基线。

## 一、审计结论与证据边界

已检查 99 关、965 波，完成 2,454 次正常经济的参考阵容模拟，以及 41 个重点节点的 816 次扰动测试。参考阵容使用当前解锁的建筑，实际结算费用、伤害、护甲、治疗、裂殖、首领阶段和漏怪。

| 发现 | 证据 | 对设计的含义 |
| --- | --- | --- |
| 不同设备的实际难度不一致 | 固定塔位编号、塔型、专精和自动操作规则，只改变尺寸，240 次对照中 74 次由桌面通关变为失败 | 应先修复布局影响战斗坐标的问题，再开始调参 |
| 整体有后期收紧趋势，局部却有明显尖峰 | 第 18 关参考通过数 1/13，19 关 9/13；39 关 3/13，40 关 12/13；86 关 2/13 | 优先处理局部编成、资源时点和布防容错，不能只统一调低或调高敌人血量 |
| 末波不一定承担最终考验 | 49 关末波的纯物理静态承伤量低于本关峰值的 80%；20 关存在相邻波回落超过 50% | 需要明确压力波、缓冲波和终波的职责，再用实际交战验证 |
| 波数公式导致章节边界时长跳变 | 59→60 关从 11 波变 9 波；79→80 关从 12 波变 10 波 | 应按章节节奏安排首领战时长；波数更少本身不代表更容易 |
| 要素已经分阶段开放，但教学仍然密集 | 6–9、11–14、16–19 关连续引入要素；13 关同时教开垦和再生敌人，16 关同时教换位和裂殖敌人 | 减少同关的独立学习任务，在章节首领前留出复习关 |
| 第 1→2 关已明显改善 | 两关均有 5/5 套基础参考阵容通过；慢操作样本也可通过 | 保留现有逐步扩建方向，继续验证真人理解和操作节奏 |

这里的“参考通过数”是固定脚本样本的表现，**不是真人胜率**。阵容库仍偏向雷鸣，不能由第 18 关的单个样本解推断“只有双雷鸣才能过”，也不能直接判定某座塔过强。

静态承伤量为 `Σ[初始护盾 + 初始生命 / (1 − 护甲)]`，不计动态治疗、补盾、幼体、速度、控制或我方成长。第 7–9 关虽然静态增长快，参考阵容却全部通过，因此这三关保留为对照，避免仅凭静态指标削弱。后期脚本结余多也不能直接说明收入过高，因为脚本建完固定阵容就停止扩建。

## 二、先解决难度不可比的问题

当前 `TowerDefenseRenderer.ensureLayout()` 会把按屏幕尺寸重新摆放的塔位写回 `gameplay.buildSlots`，战斗射程也读取同一数组。屏幕适配因此改变了塔能覆盖的道路。

拟调整为：

1. 每关有固定的逻辑道路、塔位、机关坐标；射程、光环、弹道、范围伤害和机关判定使用这套坐标。
2. 渲染器只负责投影、图标和触控布局。标签或点击区域需要避让时，保持逻辑锚点与射程提示清楚对应。
3. 点击通过稳定的塔位编号或坐标逆变换传递给玩法。窗口缩放、手机横竖屏切换不得改写战斗位置。
4. 修复后重新生成全量基线。下文的重点关卡是当前排查优先级；修复后已自然消失的问题不再额外削弱。

验收：同一关、同一逻辑操作序列、同一步长，在 1280×720、390×844、844×390 下，逐波耐久、金币、击杀和结局一致；局中切换尺寸也一致。同时检查塔位、道路、射程显示和点击区域的对应关系。

## 三、关内曲线：有节奏地加压，允许明确的缓冲波

不要求每一波都比上一波强。建议采用“较低压力起步—学习与练习—局部高点—短暂恢复—更高压力—最终考验”的节奏。

| 波次职责 | 玩家需要做什么 | 敌军和资源安排 |
| --- | --- | --- |
| 试探 | 看懂路线，建立第一段火力 | 熟悉兵种、较低密度，留出观察时间 |
| 练习／演示 | 尝试本关主题 | 新敌人先少量出现，避免立即混入多个支援体系 |
| 压力 | 补充塔位或升级，检验组合 | 提高一项主要压力，如数量、速度或装甲 |
| 缓冲 | 修补防线，准备下一轮 | 降低实际交战压力，给予可用的准备时间和收入 |
| 再加压 | 使用更完整的防线 | 引入已练过的组合，峰值高于前一轮 |
| 最终考验 | 完成本关主题 | 通常处于实际压力的最高一档；首领按本体、护卫、阶段和到达时间一起评估 |

6 波关的初始试调模板为：`试探 → 练习 → 压力 → 缓冲 → 再加压 → 终波`。预算示意为 `45 → 60 → 75 → 60 → 85 → 100`，只表示相对于本关终波的设计位置，**不是人数或血量倍数，也不是已验证的难度公式**。

4 波教学关保留简洁的扩建爬坡；5 波关根据是否教学或小首领安排一次短缓冲；7–12 波关安排 2–3 轮加压与恢复。首领可以通过阶段变化形成高潮，不必为了追上普通关波数而增加重复波。

初始试调时，缓冲预算可比前一压力波低约 10%–20%，后续压力峰值可比上一峰高约 10%–25%。这只是搜索起点：最终以正常经济下的漏怪、失败波、建造机会和实际交战时间校准，必要时超出区间并记录原因。

### 波次生成与测量方式

目前主要按波次增加数量和属性，同时循环切换编成；重甲、补盾等组合的实际代价没有被统一约束。拟为每波增加明确的职责、预算和组合限制：

- 分别记录承伤量、短时间出兵密度、速度与可攻击时间、治疗／补盾／压制／裂殖协同。多项数据并列保留，避免单一分数掩盖问题。
- 用固定道路与固定投资的对照战斗估计各兵种、支援组合的成本，再用正常收入的完整关卡模拟校准。对比需要包含穿甲、控制、范围输出等不同策略。
- 控制支援单位同时生效的重叠程度。即使支援人数比例不高，重甲、治疗、补盾同时进入火力区也可能制造尖峰。
- 新威胁先预告、再小规模展示、再混编。强组合出现前，至少给一次可负担的反制建造或升级机会。
- 记录每波开始和结束的耐久、养分、阵容、耗时；失败局记录失败波。缓冲波必须在相近的入波状态下确实更轻，不能仅仅减少显示人数。
- 终波是否合格看实际压力和主题完成度。若前面已有高潮、末波是收尾，需在关卡设计中明确标注，不能让随机轮换决定高潮位置。

## 四、整体 99 关的展开

以五关为一个小段，默认承担“引入或变式—练习—组合—挑战准备—小首领／检查点”的职责。教学关可以覆盖默认模板，第 96–99 关按四关终章单独安排。

这里的“挑战准备”不应成为普遍比检查点更难的隐性关卡；新章节开头可以适度回落，让玩家观察新环境和敌人。关卡强度要结合已开放工具、可投入养分和路线覆盖评估，不使用每关固定乘一个系数的指数增长。

| 范围 | 主要任务 | 优先审查节点 |
| --- | --- | --- |
| 1–20 | 建立扩建、范围、控制、反重装与支援处理能力；首领考核已学内容 | 保留 1–2；检查 5→6 路线切换、10／12／14 的局部波峰；重点重排 18 和 20 |
| 21–40 | 巩固基础组合，再教进阶操作；练习跃袭与补盾 | 21 作为章节适应；重点检查 28–29、33–34 的组合；修正 38→39→40 的压力关系 |
| 41–60 | 在熟悉工具下应对狂战、母体和穿刺站位 | 42、52 作为次级排查；重点 53→54→55；统一 59→60 的时长和考核职责 |
| 61–80 | 先获得观测手段，再学习潜行与压制；加强多段火力 | 61–64 的工具与敌人教学顺序；重点 73→74→75；复核 79→80 |
| 81–99 | 综合运用既有工具；通过编成变化和首领阶段增加深度 | 81 的首次机甲演示；85→86→87 的开局与中段；90 的机关依赖；96–99 的终章节奏 |

所有关卡均参与波次职责检查和完整回归。表中的节点优先手工调配，其他关卡按审计信号复核，不统一削弱。

### 重点关卡的具体处理方向

| 关卡／衔接 | 当前信号 | 拟先尝试的改动 |
| --- | --- | --- |
| 5→6 | 静态承伤量下降约 36%，但前三个塔位的参考道路覆盖合计也下降约 46% | 保持首次机关演示的低压力，核对塔位与开局投资；不能只看血量下降判断第 6 关更简单 |
| 10、12、14 | 参考方案通过数收窄，部分中间波静态峰值明显高于末波 | 将重装或支援集中波拆出明确的加压与恢复段；反制所需收入提前到位 |
| 18 | 1/13 通过；失败集中于第 3 波与末波，慢操作或换位后参考解较脆弱 | 降低第 3 波的组合突增；把黏液泉教学放在可观察的编队中；末波保留挑战并提供多种可行应对 |
| 19→20→21 | 9/13→3/13→13/13；19 仍在教新机关 | 19 改为已学内容复习；20 分离护卫压力与首领阶段；21 保留适应空间 |
| 39→40 | 3/13→12/13 | 优先拆解 39 的支援组合和密集出兵；再检查 40 的阶段威胁，避免仅为了排序硬加首领血量 |
| 54、74 | 均为 3/13；74 的选中通关方案在每 3 秒一次操作时全部失败 | 先排除几何影响，再调整开局购买窗口和支援交叠；不要求高频操作维持普通关通关 |
| 81 | 阈值机关 3/13，无机关参考 0/13 | 保留机甲首秀，降低其与既有强支援的协同；让合理布阵配合明确的关键操作可过 |
| 86 | 2/13；多数参考失败发生在第 2／4／5 波 | 优先降低开局组合压力、前移可用收入，再重建中后段高潮；避免只降低末波 |
| 59→60、79→80 | 首领关比前关少 2 波 | 按实际时长、阶段和压力重新分配预算；可以保留较少波数，但首领战需要完成章节考核 |

这些改动的先后顺序是：编成与时机 → 资源与塔位机会 → 数量和间隔 → 必要的个体属性调整。每次改动保留前后对照，以便定位真正起作用的因素。

## 五、建筑、机制与经济的展开方案

建筑解锁已形成梯度，本轮建议保留这条主线：

| 关卡 | 开放建筑 | 教学重点 |
| --- | --- | --- |
| 1 | 强酸、极寒 | 输出与减速；先建一座，再逐步扩建 |
| 3 | 熔岩 | 范围清场 |
| 7 | 雷鸣 | 连锁火力 |
| 9 | 腐蚀孢子巢 | 削甲与输出协作 |
| 12 | 虚空 | 牵引、控制与破盾专精 |
| 17 | 炽阳 | 光环或震慑协作 |
| 26 | 荆棘缚足巢 | 拦截突进 |
| 46 | 晶矛穿刺塔 | 射线站位与近身盲区 |
| 61 | 共鸣观测塔 | 先学侦测，再于 63 关接触潜行敌人 |

每次引入新塔只突出一个作用，后续关再鼓励比较分支。新塔的展示应让玩家看到收益，同时保留已学策略的合理解法。

建议把以下三个独立操作移到第二章，减少第一章双任务，并让第二章继续有内容展开：

| 机制 | 当前 | 拟调整 | 原因与配套 |
| --- | ---: | ---: | --- |
| 开垦塔位 | 13 | 22 | 13 专注再生敌人；22 在已见过的新路线中教扩展位置 |
| 弹跳换位 | 16 | 24 | 16 专注裂殖；24 用熟悉敌人教防线调动，25 再检验 |
| 母巢超载晶石 | 19 | 29 | 19 留作首领前复习；28 先认识补盾，29 用熟悉编成练习爆发窗口，30 再检验 |

这三个新节点是待批准的设计选择，尚未实测证明最优。专精 4、毒孢子机关 6、地脉 8、四级进化 11、索敌 14、黏液泉 18 保留当前解锁节点。6–9 等连续教学段先限制每关一个主要目标、保留熟悉开场，在试玩中再确认是否还需增加整关复习。

配套要求：

- 开垦后移必须与可用塔位数量解耦。13–21 关不得因延后开垦而意外减少正常防守需要的塔位、改变地脉或沿用错误的早期布局分支。
- 晶石后移后，19–28 关的敌军与资源同步重算，尤其第 20 关须在当时可用的工具内完成考核。
- 更新地图提示、教程、按钮可见性与解锁校验，保证展示和玩法一致。旧存档的关卡、星级、建筑收藏保留，回放按对应关卡规则执行。
- 首个新敌人与其反制工具可以共同服务一个教学目标；同一关不再叠加无关的新操作和复杂混编。

经济按“压力出现前能做什么”调整。需要减甲、补第二段火力或强化主塔时，相应养分应在危险波开始前可获得，不能依靠击败该危险波才拿到。优先在击杀收入与波间补给之间调整到账时点，避免一边制造前期缺钱、一边留下大量终局结余。

第一关继续遵守：一座塔能应付第一波；坚持单塔不能通关；正常资源下，合理的两座输出塔有险过空间，逐步建到三塔有稳定甚至无损解。通关条件仍是守住母巢，由敌军压力自然促使扩建。

## 六、验收标准与校准方法

以下是实施后的目标，不是对当前版本已达标的声明。

| 项目 | 验收方式 |
| --- | --- |
| 屏幕一致性 | 全部 99 关在三种尺寸回放同一逻辑方案，逐波战斗结果一致；重点关额外测试局中旋转屏幕 |
| 全战役可通关 | 正常收入、正常解锁、无测试作弊；跑完整阵容库，99 关均有可重复的通关方案 |
| 策略多样性 | 普通关目标至少 3 类有效策略，首领关至少 2 类；以核心输出／控制方式区分，不能把微调一个分支算成另一类；前两关使用有限基础塔的输出型和减速配合型目标 |
| 操作容错 | 前 20 关至少有一套匹配主题的方案能承受每 3 秒一次关键操作；后续普通关有至少一套每 1.5 秒一次操作的可行方案；首领关键操作提前预告 |
| 布防容错 | 重点普通关存在一套能够换到另一个合理覆盖位置后仍通关的方案；不要求随便放塔都能赢 |
| 第一关扩建 | 保留单塔全局失败、首波单塔成功、逐波补到两／三塔通关的专项检查；在三种尺寸均成立 |
| 缓冲与高潮 | 用相近入波状态对照，缓冲段的漏怪风险或防守投入要求低于前一压力波；末波承担最高一档考验或明确的阶段收束 |
| 学习顺序 | 强组合前有预告、演示与反制投入机会；第 19 关承担复习；界面与实际解锁一致 |
| 难度衔接 | 对尖峰关及前后关使用共同可用的策略对照，解释和消除无设计目的的断崖；检查章节开局恢复是否恰当 |
| 时长与经济 | 记录实际时长、波间等待、失败波和波前养分；避免靠重复敌军延长关卡，避免反制资金在危险波之后才到账 |
| 工程回归 | 通过现有塔防、战役、首领及正常资源测试，全量测试与构建；报告调整前后数据，保留存档兼容 |

参考库补齐无雷鸣、范围控制、穿甲单体、削甲协作等样本，并让每类策略使用适合其特点的合理塔位；避免用一种贪心择位方法替所有玩法作结论。专项对照一次只改变一个因素，如操作间隔、塔位、敌军编成或收入时点。

自动模拟用于排除无解、偶发尖峰和设备差异；“好玩、看得懂、紧张但公平”需要试玩校准。实施后建议用 6–10 名不同塔防经验的玩家做小规模探索试玩，重点覆盖 1→2、5→6、17–20、38–40、79–81；记录首次理解时间、失败原因、重试后改善与主观压力。该规模用于发现问题，不用于宣称精确的玩家胜率；若暂时无法组织，交付时明确保留这一待验证项。
