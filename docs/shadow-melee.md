# 暗影史莱姆：闪避率与暴击分身

已实施用户批准的第二版方案。暗影通过被动闪避提高生存，本体有效暴击概率生成分身，F 影袭指挥已有分身夹击。

## 开局规则

| 项目 | 当前数值 |
| --- | --- |
| 被动闪避 | 15%；虚化身躯逐级提升到 20% / 25% / 30%，配合秘典总上限 40% |
| 本体暴击 | 开局 22%，致命锋芒每级额外 +8 个百分点 |
| 分身生成 | 本体有效暴击后 60%，影生共鸣三级依次提升至 70% / 80% / 90%，不再达到 100% |
| 分身数量 | 基础 2，群影增殖提升至 3 / 4 |
| 分身时间 | 基础 4 秒，长夜留影提升至 5.5 / 7 秒 |
| 分身伤害 | 基础为当前非暴击攻击力的 40%，影刃凝实提升至 55% / 70% / 85% |
| 分身攻击 | 独立 0.7 秒间隔，0.15 秒前摇，中心射程 110px；追击范围 220px，离本体超过 360px 时回靠 |
| 影刃普攻 | 间隔 0.55 秒，身体边缘外延 72px，半宽 12px；主目标 1.05 倍，最多贯穿 3 敌，后续为 65% |
| F 影袭 | 冷却 6 秒；0.10 秒前摇、0.16 秒穿行、最多 180px；穿行免伤，落地缓冲 0.12 秒 |
| F 本体伤害 | 首个目标 1.6 倍攻击且必暴，其他路径目标 0.8 倍；本体击杀最多返还一次 0.5 秒普通冲刺冷却 |
| F 分身夹击 | 施放时已有、距离目标位置 300px 内的分身各响应一次；伤害为分身普通攻击的 2 倍，局部最多命中 3 敌 |

这些数值沿用批准方案的起始值，尚未因为单个机器人结果额外提高全局伤害。

## 概率与结算

闪避只对明确的敌方攻击判定，已有无敌优先处理；成功后免除该次伤害并虚化 0.2 秒，期间免疫敌方攻击、不重掷闪避且不刷新保护，不触发受击奖励或命中吸血。虚化不免除事件成本。普通冲刺与概率闪避都不生成分身。

每次普攻或 F 最多以第一个有效暴击进行一次分身概率判定，判定间隔至少 0.35 秒。护盾完整吸收、刺空、横斩、分身攻击不触发。暴击击杀可以生成；满额则刷新剩余寿命最短的一只，保留其攻击冷却。

分身伤害读取本体当前非暴击攻击力及等级成长，不复制暴伤或残血处决，不消费本体储存必暴，不递归生成。分身不拾取或吞噬；击杀和掉落由玩家统一结算。

分身在 220px 可见追击范围内优先选择普通法师和弓手；保持远程目标，避免来回换敌。F 夹击期间仍服从玩家指令。

普通法师和弓手可瞄准最近可见分身，距离上限 320px，且分身到敌人的距离不得超过本体到敌人的距离 +80px。守巢任务目标优先级不变，近战敌人与 Boss 不受诱导。

分身拦截普通弹幕，每发消耗 0.5 秒剩余寿命，耗尽即停止挡弹；不重置攻击冷却。按弹幕移动轨迹上的首次碰撞结算，本体前方有分身才能替本体挡弹。Boss 普攻、技能弹幕及地面范围技能不被分身阻挡。

F 按移动方向释放，静止沿朝向；本次 F 新生成的分身不参加本次夹击。目标死亡后继续攻击原命中位置附近，分身移动与伤害受地图边界、拒马和墙体限制。

T1 单级、无前置天赋「影袭留身」：成功施放 F 时立即在起点生成一只分身，无需命中，继承当前分身成长并可诱敌挡弹。满额时将最短寿命分身移至起点并刷新寿命，保留攻击冷却、取消原攻击与夹击，不参与当次 F 夹击。此生成不消耗暴击概率或触发间隔，F 命中后的暴击生影仍独立按原规则判定。未学天赋、冷却中或受阻而施放失败均不生成。

## 成长

T1：致命锋芒、虚化身躯、影生共鸣、影袭留身。
T2：影刃凝实、长夜留影、裂影横斩。
T3：群影增殖。
T4：群影共舞——分身普通攻击贯穿最多 3 敌，后续伤害 50%；F 分身攻击增加十字覆盖，同一敌人不重复受伤。

Lv.5 自动觉醒提供基础暴击保底 25%、基础暴伤保底 3.5 倍及分身移速 +15%。暴击/暴伤来源独立合成，先后获得技能与 Boss 秘典不会互相覆盖。原生黏液仍使用原有刺客玩法，公共属性覆盖问题同步修正。

虚空步为暗影提供闪避率 +10 个百分点及冲刺后的本体必暴。处决印记仅增强本体。普通技能和终极都不能让分身超过 4 个。

## 检查与结果

- `node verify-shadow.mjs`：18 组影刃、影袭、范围与输入回归。
- `node verify-shadow-clones.mjs`：35 组闪避、分身、概率、成长、兼容、生命周期、密集弹幕与 F 留身检查。
- `node verify-shadow-regression.mjs`：3 组 120 秒敌潮及 9 组无杂兵首领战；Lv.8 使用 7 点、Lv.14 使用 13 点，遵守正常预算。
- `npm test`：全部 32 个脚本通过。
- `npm run build`：生产构建通过。
- 后台浏览器验证桌面、手机、4 个真实分身、原生 F 输入、概率闪避及 HUD；未处理异常为零。
