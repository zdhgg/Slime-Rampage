# 暗影史莱姆：闪避率与暴击分身改造提案（第二版）

状态：已获用户批准并完成实施。日期：2026-10-07。本版本完整取代此前“主动冲刺留影、成功闪避反击”的提案；最终参数、验证及局限见 [实施报告](shadow-clones-report.md)。

## 1. 角色定位与范围

暗影以被动闪避率提高生存，以本体暴击概率生成持续作战的影分身。玩家通过技能分别投资暴击率、闪避率、分身触发概率、分身强度、最大数量和持续时间，形成不同构筑。

核心循环：本体近战暴击 → 概率生成分身 → 分身协助攻击 → F 影袭集中夹击。受到敌方攻击时独立判定闪避，成功则免除本次伤害。

普通冲刺沿用现有移动与无敌规则，不负责生成分身。闪避率触发也不生成分身，不返还冷却；取消旧提案的成功闪避反击、冲刺留影与相关升级。

首版覆盖计时、无尽、远征中使用暗影角色战斗系统的玩法。跑酷与塔防的独立规则不加入这些能力；换位、额外潜行、黑市新基因留作后续扩展。

下述数值是首轮试调起点，批准后根据实测小幅调整，并在交付时报告最终参数。核心触发来源、概率含义、上限与防递归规则若需更改，应另行报批。

## 2. 被动闪避率

| 项目 | 首版建议 |
| --- | --- |
| 开局闪避率 | 15%。 |
| 普通技能成长 | 每级增加 5 个百分点，3 级后为 30%。 |
| 总上限 | 40%，包含 Boss 秘典及未来加成。 |
| 触发时机 | 敌方攻击实际命中本体、且未被已有无敌挡住时，进行一次概率判定。 |
| 成功效果 | 免除该次完整伤害，显示短促“闪避”与视觉残影；不产生可攻击的分身，不视为受到伤害。 |
| 适用攻击 | 普通近战、敌人突刺、敌方弹幕、Boss 与远征 Boss 造成的攻击伤害；敌人死亡爆炸也属于敌方攻击。 |
| 不适用 | 主动支付生命、事件扣血、直接修改生命等非敌方攻击。 |

结算顺序：死亡/结束检查 → 已有无敌拦截 → 敌方有效攻击的闪避判定 → 护甲、减伤、生命与实际受击反馈。无伤害事件不掷骰，其他角色的闪避率为零且不额外消耗随机数。

一次攻击事件只判定一次，不能连续多帧重试直到失败；同一帧的独立攻击分别判定。周期伤害按其明确的伤害跳次计数。成功闪避不附赠长时间无敌，原有实际受伤后的保护照常生效。

闪避成功不触发受击加速、受击反震或敌人的命中吸血等效果。敌方攻击消耗本次出手，命中的弹幕正常消散；不得因闪避而把同一颗弹留在本体上反复判定。

## 3. 暴击生成分身

| 参数 | 开局建议 |
| --- | --- |
| 本体暴击率 | 沿用当前无基因开局的 22%（基础 10% + 血统 12%）。 |
| 暴击后生成概率 | 60%。该值是“发生有效暴击以后”的条件概率。 |
| 基础最大数量 | 2 个。 |
| 基础持续时间 | 4 秒。 |
| 基础普通攻击伤害 | 本体当前非暴击攻击力的 40%，包含正常攻击力和等级成长。 |
| 分身攻击间隔 | 0.7 秒，独立于本体的攻速，不复制多段连击。 |
| 生成位置 | 有效暴击目标附近的合法位置，呈侧翼包围；避免生成于墙内或不可达区域。 |

### 触发口径

- 仅本体普通影刃或 F 影袭造成实际生命伤害的暴击，有资格触发。
- 一次普攻或一次 F 最多进行一次生成概率判定，取该次攻击第一个实际造成暴击伤害的目标；后续目标不能在失败后补掷。
- 生成判定的最短间隔为 0.35 秒，高频攻击不能突破此频率。间隔内不积攒补发机会。
- 普攻刺空、护盾完整吸收、分身攻击、被动横斩和其他二次伤害不触发生成。
- 暴击击杀也能生成，在被击杀目标的位置附近寻找合法落点；不能因原目标已死亡而丢失奖励。
- 场上满额时，触发成功会刷新剩余寿命最短的一只分身，使其寿命恢复到当前上限，不重置攻击冷却、不额外补刀、不突破数量上限。
- 没有合法生成位置时不穿墙生成、不建立隐藏的延后召唤队列。
- 分身不能暴击，也不能生成分身；不复制本体的暴伤、残血处决或最终暴击数字。
- 生成概率达到 100% 后，满足有效暴击及频率限制时必定生成或刷新。暴击率本身仍按其数值判定。

### 开局频率校验

无升级、持续命中单个目标时，每次普攻触发概率约为 22% × 60% = 13.2%；基础普攻间隔 0.55 秒，对应平均约每 4.2 秒一次生成机会。该值是忽略刺空、位移停手与 F 的理论估算，不是固定保底间隔。

F 首个目标原有的必暴同样按 60% 生成概率结算，为开局补充生成机会。首版不增加“非暴击也能出分身”的隐藏保底。若实测前期等待过长，优先在批准的方向内调整开局条件概率或寿命，并同步更新说明。

## 4. 分身战斗行为

- 分身是短时协战幻影，优先攻击生成时的目标；目标死亡后转向附近有效敌人，不要求玩家额外选目标。
- 普通攻击为短距单目标影刃，有可见前摇；中心攻击距离 110px，索敌范围 220px，移动速度先按 260px/s 试调。
- 与本体距离超过 360px 时停止主动追敌，向本体靠拢，寿命仍正常计时；不通过瞬移跨墙打击敌人。
- 首版分身以输出为主：敌人仍按现有规则索敌本体，分身无独立生命值、不占据阻挡碰撞，也不吸收敌方弹幕。被动闪避率承担新增生存能力，避免分身数量同时成为大量额外护盾。
- 分身不拾取经验、战利品和元素，不参与吞噬；分身击杀记入玩家统计，掉落只结算一次。
- 分身伤害读取本体当前攻击力与当前分身技能倍率；伤害升级立即生效。寿命升级只影响后续生成或刷新，现存分身不会额外获得一次全体续时。
- 普通攻击、协同攻击共享分身自己的出手状态；F 指令不会在同一帧夹带额外普通攻击。

## 5. F 影袭与基础近战

F 继续提供定向穿行、首击必暴及战术集火，冷却首轮从 7 秒调整为 6 秒；前摇 0.10 秒、穿行 0.16 秒、距离 180px，沿当前移动方向，静止按朝向。

本体首个目标伤害保持 1.6 倍攻击且必暴，后续目标保持 0.8 倍攻击；穿行免伤保留，落地缓冲由 0.04 调为 0.12 秒。空场仍可脱离，完全受阻不扣冷却。原有 F 本体击杀返还一次 0.5 秒普通冲刺冷却的规则保留，分身击杀不能追加返还。

影袭夹击规则：

1. 施放 F 时记录已有有效分身。首个实际碰到的存活敌人确定夹击中心，护盾目标也可被指定。
2. 距离中心 300px 内的已有分身各沿合法路径发动一次协同突刺，每个分身、每次 F 最多响应一次。
3. 每只分身的协同伤害为其普通攻击的 2 倍：基础即本体攻击力的 0.8 倍；局部最多命中 3 敌。
4. 本次 F 暴击新生成的分身不立即加入本次夹击，从普通攻击开始作战；防止生成和夹击在同次事件中连环触发。
5. 原目标死亡后仍攻击已确定的位置附近敌人，不自动追杀远处新目标；无命中目标的 F 不触发夹击。障碍截断路径，不能隔墙伤害。
6. F 和分身夹击均不额外提供闪避率、延长分身寿命或返还 F 自身冷却。

普攻先保留 0.55 秒基础间隔、1.05 倍主目标倍率、最多贯穿 3 敌及后续 65% 伤害；判定半宽从 9 提至 12px。生命 −1、血统暴击 +12% 与普通冲刺冷却 −20% 沿用当前角色参数。

## 6. 技能树：分别投资四项分身属性

暗影使用角色专属技能变体及必要的新技能；原生黏液刺客保留原有战斗方式，不获得无效的分身技能。尽量沿用可兼容的技能 ID 与等级记录。

| 阶段 | 技能 | 级数 | 累计效果 |
| --- | --- | --- | --- |
| T1 | 致命锋芒 | 3 | 本体暴击率额外 +8 / +16 / +24 个百分点。 |
| T1 | 虚化身躯 | 3 | 闪避率 15% → 20% / 25% / 30%；替换暗影版本的暗影疾行，构筑重心转为被动闪避。 |
| T1 | 影生共鸣 | 2 | 有效暴击后生成概率 60% → 80% / 100%。 |
| T2 | 影刃凝实 | 3 | 分身普通攻击倍率 40% → 55% / 70% / 85%；F 分身协同倍率随之变为 110% / 140% / 170%。替换暗影版本的穿心绞杀。 |
| T2 | 长夜留影 | 2 | 分身持续时间 4 秒 → 5.5 / 7 秒；替换暗影版本的残影替身，提前开放。 |
| T2 | 裂影横斩 | 2 | 保留当前本体暴击触发局部横斩；横斩不能生成分身，提供分身成型前的直接群攻选择。 |
| T3 | 群影增殖 | 2 | 分身最大数量 2 → 3 / 4 个，数量提升与概率、伤害、时间独立投资。 |
| T4 | 群影共舞 | 1 | 分身普通影刃可贯穿最多 3 敌，后续目标伤害为 50%；F 协同突刺变为十字斩，扩大横向覆盖，同一敌人不因交叉重复受伤。 |

- Lv.5 自动觉醒保留本体暴击基础保底 25%、暴伤基础保底 3.5 倍，并给予分身移动速度 +15%，使觉醒对分身也有收益。
- T1 从开局进入候选；Lv.5 后任一 T1 可解锁 T2，任一分身 T2（影刃凝实或长夜留影）可解锁 T3。
- 终极觉醒需群影增殖至少 1 级、Lv.14 和现有战局进度。普通技能数量上限仍为 4，终极不额外突破数量上限。
- 暗影旧终极的暴击 ×1.5、冲刺潜行与必暴效果由新终极替换；冲刺必暴仍可由 Boss 秘典取得。
- 四项分身强化分开成长：概率提高补员频率，时间提高在场率，数量提高同时输出上限，强度提高每只分身的输出。
- 技能池提供“已走分身路线、存在可用分身升级时，三个选项至少一个为分身相关”的保底；其余选项保留随机和生存选择。只解决候选池被新增技能稀释的问题，不强制玩家点满全部属性。
- 当已满足分身路线条件且存在可用升级时，终极觉醒优先展示规则与上述保底共同满足，避免互相挤出候选。

同等等级存在取舍。以 Lv.14、正常 13 次升级为例，可选择：虚化身躯 3、致命锋芒 2、影生共鸣 1、影刃凝实 2、长夜留影 2、群影增殖 2、群影共舞 1，共 13 点；总上限为 4 个分身，但概率与强度尚未满级，且没有投资通用生命、自愈或横斩。此示例仅说明合法预算，不保证每局按该顺序抽到。

## 7. Boss 秘典与属性结算修复

- 暗影「虚空步」调整为闪避率 +10 个百分点、普通冲刺后储存一次本体必暴；不再叠乘缩短普通冲刺冷却。储存必暴造成有效伤害后，依照当前分身概率尝试生成。
- 「处决印记」保留本体暴击率、暴伤保底与残血处决；分身不继承处决倍率。
- 闪避率硬上限 40%；本体暴击率、分身生成概率各自最高 100%；分身数量首版最高 4。
- 修复已复现的普通升级覆盖 Boss 加成、觉醒后升级无收益的问题。各来源分开记录：例如暴击率先取基础/血统与觉醒保底，再加技能与秘典；结果不依赖获得顺序，显示实际增量。
- 原生黏液刺客仍需验证该公共修复，确保保留其玩法且升级不倒退；暗影新增专属能力不流入原生黏液或其他角色。

## 8. 反馈与界面

- HUD 暗影区域显示“闪避 15%”“分身 1/2”；角色/技能详情分别显示本体暴击率与“暴击后分身概率”，避免把条件概率误读成每次攻击的概率。
- 闪避成功用一次短促虚化残影与“闪避”反馈表示。纯视觉残影不计入分身数量、不攻击。
- 暴击生成分身时显示侧翼凝形动作；分身轮廓与角色一致，以明度、色彩和透明度区分本体。
- 分身普通攻击、F 突刺和终极十字斩具有可辨识的方向与范围；不遮盖敌人预警。
- 角色选择、技能预览、升级说明、秘典说明与 README 同步更新。
- 沿用 Space / Shift 和 F 及已有手机操作，不增加按键或新的大型面板。

## 10. 验收

### 机制

- 控制随机数验证闪避率、暴击后分身概率各自的失败/成功边界、零概率与满概率；多种子统计频率符合配置及触发限制。
- 闪避覆盖普通近战、弹幕、Boss 和远征 Boss；无敌、非敌方扣血及同一攻击重复帧不额外掷骰；闪避不触发实际受击/命中吸血。
- 验证本体暴击、致死暴击可生成；同次贯穿多个暴击只判定一次；护盾完整吸收、横斩、分身与刺空均不生成。
- 验证生成概率、强度、上限和寿命四类升级独立生效；满额刷新不重置攻击、不偷偷突破上限。
- 验证 F 既有分身参与、新生成分身不加入当次夹击，攻击范围、障碍与目标死亡处理正确。
- 分身不递归生成、不复制最终暴击倍率、不消费本体必暴、不重复结算击杀和掉落。
- 暂停冻结计时；死亡、结算、重开、角色切换与远征换场景清理分身、事件和待执行夹击。
- 不同升级与秘典顺序结果一致；原生黏液、其他角色、跑酷、塔防公共回归通过。

### 平衡与体验

- 相同固定种子、难度、基因、合法等级/技能预算，对照旧版暗影；不能用超过正常升级次数的满配构筑证明强度。
- 分别测试无 F 的普通攻击与常规使用 F 的玩法，记录前期首次出分身等待、分身在场率/满额率、有效伤害、清怪效率、存活时间和 Boss 击杀时间。
- 对概率、强度、数量、持续时间做单项升级对照：若数量与寿命已经常驻满额，应降低溢出收益或调整参数，不伪称每级都有同等线性收益。
- 场景至少覆盖 Lv.1–4 敌潮、Lv.5–8 成长、无杂兵 Boss、Lv.14 合法成型构筑，以及多种子长局的随机波动。
- 验证不依赖精准冲刺也能体验分身输出；被动闪避提高平均生存，但不把某个种子的连续闪避当作稳定强度。
- 首轮调优目标：前期清怪效率较旧版提升约 15%–25%，平均生存改善；后期分身构筑能成型且 Boss 输出无异常倍增。这是待验证目标，不是已测结论。
- 与其他角色做同等投入的参照，使用各自适配的操作策略；不将机器人结果等同真人胜率。
