# 单主动技能实施报告

日期：2026-10-07。依据已批准的单空格方案实施。

## 操作与界面

- 主战场 Space 释放角色主动，突围 Space 释放暴走；删除 F、Shift 战斗绑定与通用冲刺。
- WASD／方向键、E 元素交互、Esc 暂停保留。塔防移除 F 倍速热键，界面按钮继续可用。
- 主战场、突围只保留一个主动技能入口；更新角色选择页、说明、技能成长和辅助提示。
- 技能入口可点击／触摸，并支持键盘焦点；长按空格不重复释放，暂停、失焦、冷却期间的输入不延迟补发。

## 角色最终参数

| 角色 | 主动与调整 |
| --- | --- |
| 原生 | 黏液震荡：8 秒冷却、120px、1.5 倍攻击，普通敌人击退 36px；自由觉醒后保留 |
| 暴食 | 重咬保留猎食点规则；捕食护甲基础 1.6 秒，甲壳三级提升至 2／2.4／2.8 秒，触发间隔仍为 2.5 秒 |
| 弹射 | 疾射：8 秒冷却、4 轮齐射，轮次间隔 0.12 秒；移速 +20% 持续 1 秒；无目标不扣冷却 |
| 元素 | 原质释放：10 秒冷却、150px，保留 2.4 倍攻击后取整的伤害；普通敌人击退 22px、减速 30% 持续 1.5 秒 |
| 暗影 | 影袭：5 秒冷却；保留穿行、首击必暴、分身夹击，本体技能击杀返还自身冷却 0.5 秒，每次最多一次 |

首领不受新增击退和减速。元素减速独立计时，不覆盖更强的既有减速。伤害继续经过敌人护盾、受伤、击杀与掉落结算；范围攻击中途阵亡后停止后续目标结算。

## 成长迁移

- 腐蚀重碾保留 `glut_ram`：重咬伤害 +15／30／45%，外延范围 +10／20／30%，保留后续解锁关系。
- 暴食终极保留重咬半血吞噬和原有咬击成长，删除冲撞。重咬及其连锁吞噬仍不返猎食点。
- 暗影虚空步保留闪避加成；影袭结束储存一次普通攻击必暴，不由影袭自身提前消费。
- 原生刺客构筑：主动冷却替代冲刺冷却；黏液震荡触发替身，终极触发潜行与必暴。原生普通秘典保留冷却倍率。
- 动能原核保留 `kinetic_origin`：移动速度 +8%，主弹与分裂弹额外穿透 1 个目标。旧基因等级直接应用新收益，反复加载不累乘。
- 既有技能、基因 ID 和等级结构保留；不改写用户档案。

## 地图与突围

- 拒马不再受移动撞击伤害。角色按普攻间隔清理身体边缘外 48px 内的拒马，不需要场上另有敌人。
- 震荡、元素冲击、咬击和影袭落地也可伤害范围内拒马；拒马不计入敌人击杀与吞噬奖励。
- 突围移除手动急闪及其专用统计、UI、无敌和撞击奖励。道具超频冲刺继续有效。
- 换道插值由每帧 0.24 提高至 0.34；生成遭遇行保留至少一条无直接碰撞伤害通路。保留普通换道的完美闪避奖励。

- 更新旧冲刺断言，保留并运行近战、分身、资源、地图、突围融合、塔防、存档与局域网服务回归。
