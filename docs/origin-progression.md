# 原生黏液构筑成长（0.11 重构）

原生黏液不再通过 Lv.5「五系拟态」复制其他职业树。它始终以 **黏液震荡 + 异源能量 + 超载** 为核心：

- 空格主动固定为 `slime_shock`（黏液震荡），任何路线/印记都不替换；
- Lv.5 三选一**原生路线**：原质扩张 / 基因同化 / 异源共振；
- Lv.9 五选一**异源印记**：暴食 / 弹射 / 元素 / 暗影 / 共生；
- 不写 `primarySpec` / `secondarySpec`，不开放吞噬、伙伴、元素法术树、暗影分身；
- 超载时路线决定主体效果，印记只追加一次有上限的回响。

## 成长流程

| 等级 | 候选池 | 面板 |
|---|---|---|
| Lv.1~4 | 原生核心 + 异源碎片 + 通用卡 | 普通三选一；每抽至少 1 张原生卡 |
| Lv.5 | 三条原生路线 | 只弹路线确认（3 张） |
| Lv.6~8 | 原生核心 + 已选路线 + 通用 | 普通三选一 |
| Lv.9 | 五枚异源印记 | 只弹印记确认（5 张） |
| Lv.10+ | 原生核心 + 路线强化 + 印记强化 + 通用 | 普通三选一 |

## 碎片与印记

- 碎片只在 Lv.1~4 出现，每系 1 级，最多 2 个系；
- 同系印记会吸收碎片（`markState.mergedFragment`），不产生两次触发；
- 印记只提供轻量附加特征：
  - 暴食：残血回复/护甲，不吞噬；
  - 弹射：少量副弹，不分裂；
  - 元素：轻量附着，超载触发有上限的晶核回响；
  - 暗影：短隐匿 + 强化一击，不生成分身；
  - 共生：支援泡泡，不生成伙伴。

## 异源能量与超载

- 能量上限 100，超载消耗 40；
- 飞弹/震荡/元素是有效充能来源，路线效果只记录共振回路、不直接充能；
- 异源 +8、同源 +1，每秒最多结算 3 次；精英 +15、首领 +30；
- 超载乘区统一 clamp：伤害 ≤ 普通震荡 ×2.8、半径 ≤ ×1.8；
- 一次超载最多触发一次印记回响；回响伤害 ≤ 震荡基础 ×35%。

## 三条路线

| 路线 | 核心 | 超载主体 |
|---|---|---|
| 原质扩张 | 范围、副环、路线自带残留液痕 | 半径 ×1.7、伤害 ×2.0、双重冲击环、强化液痕 |
| 基因同化 | 层数、满层重组、适应减伤 | 消耗层数：伤害 ×(2.0+0.1×层数)、半径扩大、3 秒形变 |
| 异源共振 | 多源回路、充能效率 | 伤害 ×2.4、半径 ×1.4、回路额外增幅、3 回路脉冲 |

> 原质扩张的残留液痕是**路线初始能力**：Lv.5 确立路线后，每次震荡都会留下液痕；`残留液痕` 技能只强化持续/伤害/减速，不解锁该效果。同化层数基础持续 8 秒，高于 6.5 秒震荡冷却，确保无局外冷却时也能正常叠层。

## 验证覆盖

- Lv.1~4 不出现任何职业树卡；
- Lv.5 只弹 3 条路线，Lv.9 只弹 5 枚印记；
- 一局只能选一条路线、一枚印记；
- 碎片 2 系上限与同系合并；
- 超载/回响硬上限、路线效果不充能；
- 五职业回归与完整 `npm test`。
