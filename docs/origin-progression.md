# 原生史莱姆构筑成长

原生史莱姆继续保留前期自由混搭、随机错过关键卡的构筑张力。Lv.1–4 只随机提供可用的弹射、元素、暗影基础技能与通用强化；Lv.5 明确选择主拟态；Lv.6 起，原生专属成长卡和已选主树共同进入随机池；Lv.9 从其余专精中选择副专精并立即获得一项基础共鸣。这里不再增加第三次独立的路线确认，也不保证每局抽到某张成长卡。

主专精继续负责主要战斗形态与唯一的 T4 终极觉醒。副专精不开放第二个终极，只在主专精的超载主动中追加一次有限回响。双相协鸣强化这一主副关系，不改变主专精归属，也不关闭前期已经拿到的自由混搭能力。

## 原生专属成长卡

| 技能 | 基础上限 | 作用 | 硬上限 |
|---|---:|---|---:|
| 异源校准 | 6 级 | 异源充能额外增加，递减后最多 +3；同源仍为 +1 | 充能加成 +3 |
| 超载棱镜 | 6 级 | 提高已支付超载的主动伤害和范围倍率 | 超载倍率额外伤害 +45%、范围 +30% |
| 双相协鸣 | 3 级 | 增强主专精超载形态，允许副专精兑现一次回响 | 回响层数 3 |

卡片不在拟态前出现。难度和模式仍由现有技能等级规则决定实际成长跑道：简单／普通远征最多 3 级；困难远征按技能曲线扩展；地狱、12 分钟和无尽模式使用各自的技能上限。达到上限后卡片不再出现。卡片进入普通随机三选一，不提供定向保底。

## 主副协同与超载

超载仍消耗 40 点拟态能量，能量上限 100。基础异源 +8、同源 +1、精英 +15、首领 +30 的规则保留；新增的主机制和副共鸣来源共享每秒最多 3 次判定、能量上限与来源轮换状态。

主机制来源在相应的机制确实命中或触发时产生：机枪分裂弹命中、刺客暴击、元素反应／元素附魔触发、暴食重咬命中、伙伴命中。副专精只在它自己的共鸣效果实际触发时产生副共鸣来源。主机制和副共鸣异源基础 +5（异源校准可额外提高），同源仍 +1；低于常规异源 +8，避免超载回响返还过多能量。空放、无资源、冷却中、全员倒地或来源被节流时不会扣费或额外充能。

主专精决定主要超载形态：

- 弹射／元素／暗影拟态增强震荡，暴食拟态增强重咬，共生拟态增强鼓舞。
- 超载棱镜只强化已支付后的结果；它不让基础技能变成超载，也不改变释放许可。
- 双相协鸣在主树上添加一项有界回响。副树按共鸣实际效果只兑现一次：暴食对附近最多 3 个目标造成小范围伤害；弹射再追加 1–2 轮齐射；元素最多影响 210px 内当前可用的元素附魔；暗影提供最多 1.2 秒隐匿与一次必暴；共生脉冲最多命中 5 个目标。
- 回响不复制技能等级、不递归触发自己、不生成第二个终极。弹射仍受弹幕护栏约束，其他范围回响也有目标数、范围、倍率或时间上限。

副专精回响保留随机感：副专精不会让相应回响在每局自动出现；玩家需要先抽到副专精共鸣，并在超载时兑现。错过成长卡仍会构成可见的构筑差异，但不会阻止使用基础主专精主动或唯一主专精终极。

## 晶核共鸣与自动吸收

元素核心对有元素权限的角色采用短距离自动磁吸；第一颗元素核心和首次融合仍会暂停并要求确认，拒绝后核心短暂冷却，避免自动重复弹窗。经验宝石继续使用原有磁吸与升级结算，二者在外观和 HUD 中保持区分。

原生选择元素主专精后，黏液震荡会从已激活的主反应／副反应中选择元素等级最低值最高的一对，触发一次轻量晶核共鸣。火毒、雷水、火水、水毒、毒雷和火雷分别对应酸液余波、连锁电弧、蒸汽迷雾、腐蚀附着、毒雷麻痹和爆裂脉冲。共鸣不改变主形态、不激活未入槽反应、不额外产生拟态能量，也不复制全屏终极反应。

## HUD 与选卡反馈

HUD 展示主拟态、副专精、当前拟态能量、下次超载效果，以及新的充能来源类别。原生专属卡有各自的线性图标，并延用主动技能的统一图标容器。升级卡根据当前等级显示下一等级的真实收益；超载主动说明和 HUD 使用同一份派生效果，避免卡面与战斗数值分离。

## 验证

```sh
npm run test:origin
npm run build
```

原生验证覆盖拟态与副专精里程碑、随机池与血统隔离、来源窗口节流、模式等级上限、超载的主副回响和派生效果上限。

## BOSS秘典

原生拟态后继续使用独立的原生秘典池：异源导流、蓄能原核、超载余震、自适应膜，每本三级。秘典不计入主副专精投入，能量上限与超载费用保持原规则。详见 [boss-tomes.md](boss-tomes.md)。
