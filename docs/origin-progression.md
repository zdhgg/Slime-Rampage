# 原生黏液构筑成长（0.11 重构）

原生黏液不再通过 Lv.5「五系拟态」复制其他职业树。它始终以 **黏液震荡 + 异源能量 + 超载** 为核心：

- 空格主动固定为 `slime_shock`（黏液震荡），任何路线/印记都不替换；
- Lv.5 三选一**原生路线**：原质扩张 / 基因同化 / 异源共振；
- Lv.9 五选一**异源印记**：暴食 / 弹射 / 元素 / 暗影 / 共生；
- 不写 `primarySpec` / `secondarySpec`，不开放吞噬、伙伴、元素法术树、暗影分身；
- 超载时路线决定主体效果，印记只追加一次有上限的回响。

## 成长流程

| 等级 | 候选池 | 面板 |
|---|---|---|
| Lv.1~4 | 原生核心 + 异源碎片 + 通用卡 | 普通三选一；每抽至少 1 张原生卡 |
| Lv.5 | 三条原生路线 | 只弹路线确认（3 张） |
| Lv.6~8 | 原生核心 + 已选路线 + 通用 | 普通三选一 |
| Lv.9 | 五枚异源印记 | 只弹印记确认（5 张） |
| Lv.10+ | 原生核心 + 路线强化 + 印记强化 + 通用 | 普通三选一 |

## 碎片与印记

- 碎片只在 Lv.1~4 出现，每系 1 级，最多 2 个系；
- 同系印记会吸收碎片（`markState.mergedFragment`），不产生两次触发；
- 已拥有碎片会显示在 HUD 变异方向栏；暴食碎片按**震荡结算前**的残血状态判定；
- 元素碎片在未吸收元素核心时不会触发，卡片与 HUD 会明确提示；
- 碎片 ICD 压缩到 2~10 秒（震荡 6.5 秒），大部分碎片每 1~2 次震荡就有一次可感知触发；
- 印记只提供轻量附加特征：
  - 暴食：残血回复/护甲，不吞噬；
  - 弹射：少量副弹，不分裂；
  - 元素：轻量附着，超载触发有上限的晶核回响；
  - 暗影：短隐匿 + 强化一击，不生成分身；
  - 共生：支援泡泡，不生成伙伴。

## 异源能量与超载

- 能量上限 100，超载消耗 40；
- 飞弹/震荡/元素是有效充能来源，路线效果只记录共振回路、不直接充能；
- 异源 +8、同源 +1，每秒最多结算 3 次；精英 +15、首领 +30；
- 超载乘区统一 clamp：伤害 ≤ 普通震荡 ×2.8、半径 ≤ ×1.8；
- 一次超载最多触发一次印记回响；回响伤害 ≤ 震荡基础 ×35%。

## 三条路线

| 路线 | 核心 | 超载主体 |
|---|---|---|
| 原质扩张 | 范围、副环、路线自带残留液痕 | 半径 ×1.7、伤害 ×2.0、双重冲击环、强化液痕 |
| 基因同化 | 层数、满层重组、适应减伤 | 消耗层数：伤害 ×(2.0+0.1×层数)、半径扩大、3 秒形变 |
| 异源共振 | 多源回路、充能效率 | 伤害 ×2.4、半径 ×1.4、回路额外增幅、3 回路脉冲 |

> 原质扩张的残留液痕是**路线初始能力**：Lv.5 确立路线后，每次震荡都会留下液痕；`残留液痕` 技能只强化持续/伤害/减速，不解锁该效果。同化层数基础持续 8 秒，高于 6.5 秒震荡冷却，确保无局外冷却时也能正常叠层。

## 源质记忆（Origin Essence Memory）

原生黏液击败带源质映射的首领后，可以在**现有的首领奖励面板**里吸收该首领的源质，
把它重新长成自己的技能；这些技能不需要任何新按键，只在**真正支付超载**后自动释放。

| 规则 | 数值 |
|---|---|
| 记忆槽位 | 最多 3 种不同源质 |
| 技能等级 | 每种 Lv.1~3，重复获得升级 |
| 获取方式 | 首领奖励候选卡（与本职秘典共用同一面板与暂停流程） |
| 首次保底 | 本局第一次遇到某种源质时**必定**进入奖励流程（绕过 65%/85% 判定，每种一次） |
| 编队取型 | 一场编队按「未学 → 等级最低 → 满级跳过」挑一种，不再只看最后阵亡的成员 |
| 释放时机 | 成功超载后延迟 0.2 秒自动释放一次 |
| 释放顺序 | 按吸收顺序轮换，每次超载一个 |
| 充能 | 源质技能不产生异源能量，也不触发印记回响 |

> 保底只影响「是否出现面板」，不改变面板内三选一的结构；每局最多因此多出 3 次首领面板（三种源质各一次）。远征每章本来就是 100%，不受影响。

| 源质 | 技能 | Lv.1 | Lv.2 | Lv.3 |
|---|---|---|---|---|
| 骑士王（`boss-knight`） | 破阵凝胶波 | 一道直线冲击波 | 更宽更长、击退更强 | 末端追加液态爆发 |
| 大法师（`boss-mage`） | 奥术坍缩 | 密集处原核 + 范围爆发 | 范围与伤害提高 | 坍缩后追加扩散冲击 |
| 弓王（`boss-archer`） | 棘刺追猎雨 | 3 枚追踪棘刺 | 4 枚、伤害提高 | 5 枚、追踪与穿透提高 |

路线联动（各自独立，互不叠加）：

- **原质扩张**：攻击范围 +10%~15%（只加覆盖，不追加独立伤害，附带扩散波纹）；
- **基因同化**：按**超载触发前**的同化层数增伤，每层 3%、封顶 15%（超载消耗的是快照里的层数）；
- **异源共振**：超载前达到 3 回路时追加一次 25% 的共振余波，不充能、不递归。

安全约束：源质技能击杀仍走统一结算（经验/掉落/击杀统计照常），但**跳过异源充能**，
避免「源质技能击杀 → 充能 → 更快超载」的自循环；单次释放的实体数量固定
（棘刺硬上限 12），不参与普通飞弹的分裂/元素附魔/暴击链。

手感修正（第二轮验收）：

- **破阵凝胶波**的命中带随飞行距离外扩（半宽 `width × (0.5 → 0.85)`），从等宽细线改成楔形凝胶波，
  空放率从 22% 降到 2–10%；
- **首领优先**：破阵凝胶波朝视距内的首领发射（直线沿途照样扫到杂兵）、棘刺第一枚锁首领、
  坍缩的密集点对首领所在簇加权——"吸收 BOSS 力量"因此真的会落到 BOSS 身上。

## 验证覆盖

- Lv.1~4 不出现任何职业树卡；
- Lv.5 只弹 3 条路线，Lv.9 只弹 5 枚印记；
- 一局只能选一条路线、一枚印记；
- 碎片 2 系上限与同系合并；
- 超载/回响硬上限、路线效果不充能；
- 源质记忆：首领奖励必出对应卡、升级/封顶/槽位、超载轮换、三路线联动、无充能无递归；
- 五职业回归与完整 `npm test`。
