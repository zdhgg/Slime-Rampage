# 元素史莱姆：双元素法术与法术核心实施方案

日期：2026-10-14。状态：已由用户批准并实施。实际规则与验收记录见 [实施说明](elemental-spells-implementation.md)。下文保留批准时的方案。

## 目标与范围

将元素史莱姆的主要攻击改为具有不同攻击行为的法术。每局最多掌握两种元素，拥有两套自动基础法术、一个由空格释放的融合主动术。融合反应是基础法术之间的互动，不额外占一个施法技能位。

覆盖主战场的王庭逆袭、限时讨伐、无尽灾变。其他血统、原生黏液的自由构筑、跑酷和塔防沿用现有玩法；共用模块通过血统分支接入新系统。工作区已有其他角色相关未提交改动，实施时保留并基于其当前状态进行增量修改。

## 一、局内流程

1. 选择元素史莱姆时，显示火焰、寒冰、雷电、毒素四个起始选项，默认火焰。开始按钮附近明确展示本局选择。将选择传入开局和重新开始流程。
2. 开局掌握一种基础元素，自动施法；空格使用当前原质释放的近身解围技能。生命减一与暴击加成先保留。
3. 首次有效 BOSS 遭遇胜利，保底获得一颗未定型「法术核心」。首次核心展示剩余三种元素，每张卡同时说明新基础法术、融合反应和空格融合术。选择后立即融合，本局组合固定。
4. 后续有效 BOSS 遭遇胜利，每次提供一颗法术核心。三选一奖励根据当前组合生成，改造基础法术、强化融合反应或进化空格技能，不增加第三元素和额外技能位。
5. 普通怪、精英和世界事件不再为元素史莱姆发放旧随机属性核心；原生黏液仍走旧掉落规则。

首次融合安排在首个 BOSS 奖励，第一版不额外添加精英融合入口。验证首领前单系法术的战斗体验与等待长度，再决定是否需要提前奖励。

## 二、四种自动法术

| 元素 | 法术 | 行为与索敌 |
| --- | --- | --- |
| 火焰 | 火球术 | 向目标飞行，命中爆炸并燃烧；优先可造成范围收益的敌群及融合标记目标 |
| 寒冰 | 寒冰箭 | 沿瞄准方向穿透有限目标，施加冰霜；积累后冻结普通敌人，优先近处威胁 |
| 雷电 | 闪电链 | 瞬间打击并在有限距离内跳跃，不重复命中同一目标；没有跳跃目标时仍有完整首击收益 |
| 毒素 | 毒雾 | 在射程内的目标群附近生成持续区域，周期伤害并中毒；限制同时存在的区域数 |

两个元素独立冷却，第二系加入不削减第一系原有频率；错开初始施法时机。无有效目标时等待，暂停期间不推进计时。核心施法采用稳定触发，额外增益可以采用概率。

寒冰是元素史莱姆的显示名称，共用旧水流数据按角色兼容。雷电麻痹与寒冰冻结在新系统中区分表现。BOSS 受控制抗性约束，不被永久冻结、击退或连续打断。

攻击与状态伤害接入现有统一伤害、击杀、掉落与地图障碍处理；地图中的可攻击物仍能被适用法术命中。通用攻击成长正确作用于法术，弹数、弹速、穿透等升级按当前法术提供有效映射或在候选池中过滤。

## 三、六种融合与空格技能

| 组合 | 自动融合反应 | 空格融合术 |
| --- | --- | --- |
| 火＋冰 | 火焰命中冻结目标产生霜火碎裂 | 霜火爆裂：目标区域施加冰霜并引爆，普通敌人受到短控制 |
| 雷＋冰 | 闪电命中冰霜目标产生强化传导与冰晶爆裂 | 雷霜风暴：范围冰霜与连锁雷击 |
| 火＋毒 | 火焰点燃毒雾，触发范围爆燃 | 爆燃领域：主动生成毒雾并立即引爆 |
| 雷＋毒 | 雷电激活毒雾中的目标，触发毒电连锁 | 毒雷风暴：主动生成毒域并释放雷击 |
| 冰＋毒 | 毒雾对冰霜目标强化减速与冻结积累 | 寒疫领域：生成毒域并快速积累冰霜 |
| 火＋雷 | 雷电引爆燃烧目标的标记，触发雷火爆发 | 雷火轰击：对目标区域发动集中雷火打击 |

空格采用自动瞄准，默认冷却 10 秒作为初始调试值。有效施放保留轻量近身击退，普通敌人适用，首领不位移。融合术能自行创建所需状态或区域，无需等待自动法术预先满足条件。

若没有攻击目标，也没有需要解围的近敌，不消耗空格冷却。长按、暂停输入和重复按键沿用单次触发纪律。

融合反应设置独立触发间隔与单帧预算；反应伤害不再次递归触发自身或其他反应。区域数量、连锁目标数、持续时长均有上限，法术结束或目标死亡后及时清理。

## 四、法术核心奖励与成长

首次核心仅负责选择第二元素并确定融合。后续核心提供三种有意义、适用于当前组合的候选；候选明确展示前后效果与强化等级。

第一版为六种组合各提供基础法术改造、融合机制改造、主动术进化的成长路径。行为改造有等级上限，主动术达到高阶时升级现有技能的名称与演出，例如火毒从爆燃领域进化为灾炎领域。进化替换旧形态。

无尽模式的行为改造耗尽后，继续提供有用的自动法术伤害、融合反应伤害、主动术伤害强化；避免空候选、重复无效升级、无限缩短冷却或无限扩大范围。

普通升级负责施法强度、冷却、范围和持续效果等常规成长；BOSS 核心承担明显的行为变化。重写元素血统的旧附魔概率、四系混沌与全元素被动选项，升级候选始终适用于当前已掌握元素。Lv.5 仍自动觉醒元素专精。

元素角色的旧 BOSS 职业秘典纳入法术核心奖励；旧 BOSS 免费秘籍不再作为额外元素奖励同时弹出，奖励强度按新核心预算校准。经验、货币与关间补给按各自原有来源结算。

## 五、BOSS 与奖励状态管理

- 单个章节守将算一次有效遭遇；一个首领编队在全队结束时发放一颗，共用遭遇标识去重。
- 击败 BOSS 后显示法术核心掉落与吸收演出，自动进入奖励队列，不要求靠近或按 E。
- 奖励选择串行处理，协调普通升级、觉醒、核心选择和关间补给的暂停状态。
- 远征先完成法术核心选择，再进入下一关补给；奖励不依赖容易被章节清理移除的地面物品。
- 最终胜利或死亡优先完成结算；已终止战斗不再弹出无后续用途的强化选择。
- 同一帧多个法术、DOT、反应击杀同一个 BOSS，只结算一次。

## 六、界面、表现与存档兼容

出战页增加起始元素选择与施法预览；HUD 展示两格元素、一个融合名称、当前空格技能及冷却。元素史莱姆隐藏旧四格核心、副反应槽、消化成长和 E 吸收提示；原生黏液继续使用适用的旧界面。

新法术采用现有 Canvas 渲染方式，提供核心亮起、施法、命中和音效反馈。基础特效克制，融合与空格演出加强，保证敌方弹幕和 BOSS 预警可读。完成桌面及窄屏布局验证。

保留存档中的基因购买等级、货币和记录。旧共鸣槽位基因针对元素史莱姆转为融合伤害或主动术范围等收益，并同步角色适用说明；针对原生黏液保留原有槽位收益。旧共鸣原核保留既有反应伤害收益，将元素血统的额外槽位收益转换为主动术收益。重新开局不继承上一局核心强化。

## 七、实施顺序

1. 增加角色独立的法术、融合与核心奖励数据，定义运行状态及边界。
2. 实现四种基础法术、独立计时、索敌与统一伤害接入。
3. 实现六种融合反应、六种空格融合术与反应限流。
4. 实现 BOSS 核心奖励、首次选择和后续强化，接入遭遇去重及奖励队列。
5. 调整普通升级、旧 BOSS 秘典和基因角色分支，保留存档权益。
6. 完成出战页、核心选择、HUD、法术演出及角色说明。
7. 执行功能测试、构建、浏览器实战与数值初调，交付说明和验证结果。

主要接入文件包括 GameEngine.js、WeaponSystem.js、StrainSkills.js、SkillPool.js、GenePool.js、GemManager.js、Player.js，以及 App.vue、StartScreen.vue、StrainSelect.vue、HudOverlay.vue、LevelUpModal.vue。新增专门的元素施法与核心奖励模块，避免将全部行为堆入通用武器系统。

## 八、验收标准

- 四种开局法术可用，攻击行为可辨认；六种组合均完成自动反应和主动施法。
- 每局最多两种元素、两套自动法术、一个空格技能；进化不增加技能位。
- 首颗核心明确选择第二元素，后续核心三选一全部有效，强化即时生效。
- 普通怪与精英不再为元素角色掉旧属性核心；每次有效 BOSS 遭遇奖励恰好一次。
- 远征转场、编队首领、同帧击杀、普通升级重叠、暂停与结算不丢奖励、不叠面板、不残留暂停锁。
- 冷却、施法、状态和伤害在暂停、重开、死亡后正确停止或重置。
- 通用升级和已有基因对元素角色均有有效收益；原生黏液及其他角色关键回归通过。
- 新增有意义的元素机制测试，并运行相关引擎、单键操作、首领、存档、模式回归；完成 npm test 和 npm run build，报告基线已有失败与新引入失败。
- 浏览器检验桌面、窄屏、六种融合演出、BOSS 核心选择与连续战斗；性能检查覆盖区域、链式攻击和反应高密度场景。

自动化测试证明机制正确；最终数值手感以实际游玩为准。本轮进行首版强度与可读性校准，后续可根据用户试玩反馈继续调整。
