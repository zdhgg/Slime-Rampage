# 黑市基因成长

黑市是跨局档案成长：**货架只卖全血统通用的改造**——任何血统购买即生效，不再有「这个血统能不能用」的适配说明。旧存档中的基因 ID、等级继续有效；旧战利品存量已按购买力 ÷15 折算为**战力点**（V5 惰性迁移）：下架的血统专属基因保留定义与效果，但不再出售；旧原核摘除互斥标记，不占用新原核的位置。

## 战力点（货币）

战力点不再靠怪物掉落，而是**由本局分数统一折算**：`战力点 = round(分数 × 难度倍率 × (1 + 无尽加成) × 保留率 ÷ 30)`（`scoreToPoints`，`src/game/RunRules.js`，V6 起收支同步采用 ×100 展示尺度）。锚点：困难通关约 1100 点、普通通关约 800 点、地狱通关约 1800 点；中途暴毙按分数自动低保（约 200~400 点），无需单独的保留率规则。无尽模式沿用撤离 100% / 战败 70% 与灾变+继续加成（封顶 2.5），超过 2000 点的部分减半，防止深层无尽单局打穿货架。客户端预览与服务端入账共用同一公式，客户端不再上报掉落数量。

## 通用属性接线口径

- **伤害**：`weaponSystem.damage` 是飞弹、暴食咬击、暗影影刃与法术 `baseDamage` 的共同源头，单一基因全体生效；
- **攻速**：`fireInterval` 经 `attackInterval` 进入近战摆动节奏与远程开火冷却；
- **攻击范围**：`weaponSystem.geneRangeMul` 由四处读取——飞弹/分裂弹 `life`、暴食 `GluttonCombat.reach()`、暗影 `ShadowCombat.reach`、法术 `SpellCombat.rangeScale`（在局内 1.65 上限之外乘算，外源修饰不吃封顶）；伙伴攻击不在此列；
- **噬血**：`WeaponSystem._tickLeech` 挂在 `_settleKill` 与 `onDevoured` 两个击杀结算入口，阈值受 `geneLeechKillsMul` 折扣，下限 8；
- **无敌帧**：`Player.hit` 的 0.5 秒基础无敌 × `geneIFramesMul`；护盾抵挡的 0.18 秒短帧不受影响；
- **困兽/玻璃增伤**：`weaponSystem.damage` 改为 getter/setter——读取时乘残血倍率 `_furyMul`，写入时折算回基础值，`*=` 乘算更新不被血线污染，全部伤害路径零改动接入；
- **狩猎亢奋**：`attackInterval` 乘 `_huntRushTimer > 0` 时的 `geneHuntHaste`，`_settleKill` 与 `onDevoured` 两个击杀入口统一刷新窗口；
- **涌泉**：`Player.gainExp` 累计 `_siphonProgress`，达 `maxExp × geneSiphonRate` 回血，与噬血共用 `_leechHealCd`；
- **复苏茧**：`Player.hit` 致命分支先查 `geneCocoon`，每局一次；
- **备选蓝图**：`GameEngine.rerollSkillOptions` 重抽 `openFreeSkillPanel` 候选，里程碑/路线/招募面板经 `_skillPanelRerollable` 标记排除；
- **扩容视界**：`GameEngine._skillOptionCount()` 统一控制升级、秘典与悬赏面板的抽卡数；
- **全域磁感**：`GemManager` 拾取判定在 `geneMagnetAll` 时把半径视为世界对角线。

## 旧基因下架规则

下架基因标记 `hidden`：`getGenePurchaseState` 直接拒绝（服务端购买 API 同源拒绝），UI 因 branch `legacy` 不在货架表而自然不渲染；`applyGenes` 仍按存档等级应用，旧投资不蒸发。旧原核摘除 `exclusiveGroup`，可正常生效但不阻止购买新原核。

## 购买与验证

成本沿用早期可触达、后期递增的曲线：÷15 货币折算重定价后整体上调约 1.5 倍（在售基因下限 200 点，单调不减）；违禁品为一次性买断。货架全价 26700 点＋一件违禁品 600~1000 点＋终点原核 2200~2500 点，毕业线约 29900~30200 点 ≈ 25 局困难通关。`BlackMarket.vue` 货架区三栏展示收益预览，暗格区以副作用文案标注代价。

专项验证为 `node verify-black-market.mjs`，覆盖新原核依赖互斥、火力派生、噬血计数与回复间隔、范围四端接线、违禁品副作用、旧基因下架保留与幂等应用。全局回归继续纳入 `npm test`。
