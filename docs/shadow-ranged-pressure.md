# 暗影后排处理调整

针对近战围堵时法师持续积累的问题，修正分身的射程覆盖与主动指令。

- 法师攻击距离为 340px，旧分身搜敌仅 220px。分身现在优先寻找 420px 内、距本体不超过 520px 的可见法师／弓手。
- 追击射手的基础速度从 260 提至 420px/s，觉醒后的 +15% 继续生效。普通追敌速度不变，回收距离改为 520px。
- 影袭命中普通前排时，已有分身优先分派到不同后排射手；没有可达射手则继续攻击首击目标，首领指令仍集中夹击。
- 分身普攻锁定射手后不会被刀路上的前排抢走唯一命中；突袭为指定目标保留一个命中名额，仍最多命中三敌。
- 保留伤害倍率、数量上限、挡弹寿命消耗、冷却和墙体阻挡规则，没有全场自动清弹或全局削弱远程敌人。

验证：`verify-shadow-ranged.mjs` 覆盖射程、实际追击命中、前排遮挡、指令分派、首领集火与墙体限制。固定四前排／340px 四法师／四个满伤害成长分身、3 秒静态输出对照中，旧搜敌与前排集火规则击杀 0，调整后击杀 4；此对照隔离输出路径，不代表完整战斗胜率。

原有暗影近战、35 组分身契约、单主动技能以及三组 120 秒敌潮／九组首领战回归通过。真人密集弹幕环境仍需实际体验；本次解决分身无法到达和无法命中后排的问题。
