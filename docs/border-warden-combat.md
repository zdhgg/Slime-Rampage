# 边防官专项优化与验收

## 范围与基线

仅 `border_warden` 在 EnemyManager 中选择新的 BorderWarden 子类；其余十一章首领、普通 Boss 和塔防首领保持原实现。没有增加闪避、耐力或角色专属克制逻辑。

原工作区已有未提交的 Boss、美术、对白等修改，本分支从当时 HEAD 建立独立工作树，未混入这些修改。报告与测试针对本分支的完整版本；原工作区内容保留。

## 原机制问题分类

* AI：骑士追击基础速度 55，远低于玩家 340；追击与强招冷却相互独立，无法根据距离组织接近、压制、收势循环。
* 技能：提交基线的边防官继承贴身即时普攻，强招也缺少完整的近战接近/衔接；单纯把强招改成原地近战仍会留下远程风筝问题。
* 时序与表现：贴身普攻缺少独立预警；朝向直接指向玩家，连续段更像冷却后重新施法；需要逐段锁定方向和共享预警判定。
* 参数：二阶段加速、加攻频，75% 额外护卫、25% 再加速，容易把角色差异变成伤害叠加问题；基础追击速度差又使远程交战过于安全。
* 构筑：近战需要可接近的停留窗口；毒雾、伙伴和延迟投射物需要 Boss 有足够停留时间，不能只给瞬间反击机会。

## 实际方案

行为只读取位置、距离、移动趋势和战斗状态，不读取角色 ID。

1. 追击以基础 195 速度推进（保留难度移速乘数、地形与减速影响），不会持续以冲锋速度追踪。普通行动转向上限 4.8 rad/s。
2. 距离小于 155 选择盾扫；155–240 选择枪刺；更远在有限追击后选择冲锋。盾扫范围 148、半角 1.05；枪刺范围 245、半角 0.25；冲锋最大距离 600、宽度 116，场边裁剪。
3. 一阶段近距盾扫 → 0.32 秒衔接 → 独立预警枪刺；远处冲锋后收势。基础预警分别为 0.52/0.64/0.72 秒，另加有限转身时间。
4. 二阶段近距盾扫 → 盾扫 → 跨步 → 枪刺；中远距枪刺或冲锋 → 跨步 → 枪刺。跨步无伤害、最多 160，随后完整预警；不是额外瞬移攻击。距离超过 480 不跨步追击，普通续段超过 300 则结束，禁止无限续追。
5. 冲锋根据玩家角向移动趋势进行有上限的预判，最大偏角约 63°；整段预警一开始就固定区域，执行期间不追踪。攻击锁定后变向能够可靠脱离，固定同向绕圈有受击风险。
6. 整套结束原地收势 2.4 秒 / 二阶段 2.7 秒，继承原有 1.8 倍破绽承伤；再经过 0.55 秒重新进攻准备。没有新增接触伤害、弹幕、额外召怪或残血加速。伤害固定 2，仍经过玩家无敌帧/护甲/护盾/闪避与敌方削弱结算。
7. 冲锋扫掠使用分步积分与线段范围判定，每次攻击有独立事件，整次冲锋最多命中一次；冻结/硬直暂停攻击计时并保留收势窗口。玩家移动估计按真实帧采样，避免低帧率子步采样丢失速度。
8. 半血取消未执行的旧预警、连段和位移，0.85 秒转阶段后使用新组合；不再靠提高伤害和速度区分阶段。

## 自动化与浏览器验收

* `npm test`：全项目回归，包括本轮新增专项入口。
* `npm run test:warden`：16 组机制验证 + 18 个真实武器组合场景。包含两个阶段、15/30/60/120 FPS、锁向后脱离、冲锋单次命中、场边裁剪、冻结保留计时、削弱结算、转阶段取消、限制追击、绕圈与预警后反向对照。
* 18 场景：六种角色，其中元素展开成火/冰/雷/毒四种；Lv.4、无局外基因、基础等级攻击增长；暴食一层甲壳、暗影一层生影、弹射一层齐射、共生一层伙伴伤害，火焰/毒素各一层附着。使用真实 Player/WeaponSystem/EnemyManager，25 秒脚本移动，不提高玩家生命或赋予无敌。所有组合能造成伤害，近战组合均在收势内完成输出。
* 脚本路线不代表通关胜率。毒素中距脚本约 15.4/25.2 伤害（两个起始阶段），冰/雷约 37–43，带燃烧的火焰约 54–56；说明毒素仍有明显耗时风险。远距毒素输出更低，应人工确认中距诱导是否有趣、升级后的持续伤害是否足够。未改动元素系统以强行拉平输出。
* 固定圆心、410 半径、340 速度、60 秒同向绕圈，在各帧率/阶段均发生命中；预警后反向脚本均能躲避。它验证路线需要调整，不证明所有半径或高移速构筑都不存在安全循环。
* 浏览器：真实 Edge 无头运行、真实 Canvas 和键盘事件，六种角色分别进入二阶段，与骑士/弓手/法师三名残兵共存，验证移动和自动攻击并截图，页面运行错误为零。普通怪更近时，自动索敌会优先攻击普通怪；这是保留的割草系统行为。
* `npm run build` 成功；构建仍提示原有大体积 bundle 警告。

本地浏览器截图与 JSON 输出：`.workbuddy/warden-browser/`（不纳入提交）。

## 人工试玩入口与待确认清单

运行 `npm run dev -- --port 3017`，打开 `/test-support/warden-playtest.html`；可以选择六角色、四基础元素、起始阶段、三名残兵，WASD/方向键移动、空格主动。该页面使用普通基础成长，不写存档；为了隔离 Boss 交战，关闭章节推进和障碍碰撞，因此不用于地图障碍验收。

必须人工确认：

- 暴食能否自然利用窗口积累猎食点并重咬，暗影的主动影袭是否有足够收益；不能以概率闪避作为必需解法。
- 毒素的中距留场策略及首战总耗时，远程弹射的长距离与加速模块是否仍形成过于安全的循环。
- 共生伙伴在长距离换边后能否及时跟上；伙伴控制、毒雾与视觉效果大量叠加时预警是否清楚。
- 小地图边角、实际地图障碍、移动端触控、不同视口与高移速成长下的冲锋可读性。
- 密集残兵、已有敌方弹幕、多方向包围的长局战斗；浏览器的三残兵短测不能证明所有叠加都合理。
- 完整自然成长流程的击杀耗时、真实操作容错与二阶段节奏；目前验证的是机制可执行性和输入渲染连通性，尚无人工长时间试玩数据。
