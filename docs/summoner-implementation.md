# 共生史莱姆

第六种主战场血统，专精为「共生契约」。选择页、角色预览、战场本体和宠物状态栏均已接入，沿用空格主动技能。

## 战斗规则

- 开局携带岩甲团团：9 点生命，普通攻击为本体基础攻击的 1.4 倍，间隔 0.85 秒。附近最多三名普通敌人可被护卫吸引，首领仍攻击玩家。
- 学习「疾风伙伴」后获得疾风芽芽：6 点生命，攻击倍率 1.15，间隔 0.65 秒，优先追击法师和弓手。最多两只长期伙伴。
- 空格「协同狩猎」冷却 7 秒，按移动方向（静止时按朝向）寻找前方目标。护卫发动最多三目标的 2 倍范围攻击，猎手发动 3 倍单体攻击；没有目标时回防 2.5 秒，期间承伤减半。全部倒地时不消耗冷却。
- 宠物有独立生命，倒地 8 秒后在玩家附近恢复；3 秒未受伤后每秒恢复 0.35 点生命。普通敌弹可被宠物拦截，首领弹幕穿过宠物。
- 伙伴攻击有前摇、距离与视线检查，不穿越地图障碍。伤害通过统一击杀入口发放计数及掉落，不触发本体暴击、元素、吞噬或分身链。
- 本体飞弹伤害降低 45%；宠物使用完整基础攻击及等级倍率。Lv.5 自动觉醒后宠物伤害增加 20%。

## 成长

兽灵共鸣（伤害）、坚韧伙伴（生命）、默契步调（攻速）→ 疾风伙伴／迅速复苏（倒地缩短至 5 秒）→ 协同猎令（主动伤害）→ 双生守望（双伙伴存活时伤害额外增加 30%）。

两项首领秘典分别强化玩家生命和指令冷却。共生主树仅对共生角色提供，不进入原生的自由专精选择。
