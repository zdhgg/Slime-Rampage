# 技能等级成长规则

技能上限由 `src/game/SkillProgression.js` 根据模式、难度和技能成长类型统一解析。卡牌展示、抽取过滤和应用入口使用同一有效上限。

| 模式 | 通用技能 | 主轴技能 |
|---|---:|---:|
| 王庭逆袭：简单 / 普通 | 最多 3 级 | 最多 3 级 |
| 王庭逆袭：困难 | 最多 3 级 | 通常 6 级；经审核的技能按效果曲线扩至 7–8 级 |
| 王庭逆袭：地狱 | 最多 4 级 | 通常 10 级；经审核的技能按效果曲线扩至 9–12 级 |
| 限时讨伐：12 分钟 | 最多 3 级 | 通常 5 级；少数主轴成长技能扩至 8–10 级 |
| 无尽模式 | 按技能定义 | 主轴通常 10 级；经审核的成长型技能扩至 12–14 级 |

主轴技能只有在主专精或弹射路线确立后才开放扩展等级。成长类型通过 `growthClass: 'core'` 显式加入；一次性终极、伙伴招募、连锁和其他离散机制保留自己的上限。核心等级是可达到的上限，不保证每局升满。

等级不强求统一数字。技能在模式基础值上可配置自己的上限：例如弹速伤害、移速冷却、元素反应、伙伴培养以及弹射追猎各有不同的延伸幅度。扩展到高等级的技能要有逐渐减弱的每级收益，或明确的离散效果上限；当效果已经触顶，就停止出现升级卡。

无尽模式给已确认路线的主轴技能更长的成长跑道，但这些等级仍然是有限的；只有少量适合重复投资的技能可无限升级：`余烬共鸣`、通用的`流体滑行`／`引力细胞`。无限技能按总等级重新计算，并以软上限递减；卡片在第 25 波起加入无尽精通。弹射分裂路线的`子弹追猎`最高 10 级；伤害按小步幅逐级增加，存续时间封顶，避免无限抽卡却没有新的实际收益。

玩家等级提供的攻击成长在常规模式保持每级 ×1.08。无尽模式保留前 20 次升级的节奏，之后逐渐收敛到 ×6；余烬共鸣作为单一有界因子叠加，累计趋近 +50%，不会逐级对当前倍率重复相乘。弹射弹体总量继续受 320 枚护栏约束，分裂子弹不会递归分裂。

验证：`npm run test:skill-progression`、`npm run test:ricochet` 与 `npm run test:ricochet-browser`。
