# 原生黏液：多技能超载与稀有核心

这是当前实现的规则。旧单技能版本与掉落基线保存在 `origin-combo-baseline.md`。

## 超载配置

- 原质环流先天拥有，吸收首领源质后仍然保留。
- Lv.2～4 的普通三选一保底包含原质冲波发现候选，玩家可选择先培养其他能力。
- 首领源质仍有三种：破阵凝胶波、奥术坍缩、棘刺追猎雨；每种最高三级。
- 最多装备四项能力，指定其中一项为主技能；其余作为随机协同候选。
- 在普通升级或首领奖励暂停期间，通过左下角“超载配置”调整；战斗中拒绝修改。
- 自动装备新能力直到四项，未装备的能力与等级不丢失；原质环流也可重新装备。
- 协同抽取采用随机洗牌袋：一轮内不重复；暂时无目标的技能保留出场机会。

## 释放与成长

- 能量上限100、一次超载消耗40；冷却普通6秒、共振5.5秒，启动表现0.25秒。
- 进入启动不扣费；确认主技能有目标后才支付。无目标保留能量。
- 主技能无法触及目标持续约2秒时，可暂用装备中有有效目标的能力；指定主技能不被改写。
- 主技能后约0.35秒释放一项有效协同；每个后续技能重新索敌。
- 主技能使用独立释放伤害；协同使用60%。解锁“多重超载”后每第三次成功超载追加第三项不同技能，使用40%。
- 多重超载至少装备三项能力才进入候选；发现与多重超载均为一次性解锁，无尽模式也不能重复购买。
- 源质基准系数为3.25；统一伤害乘区上限1.8、范围乘区上限1.35，协同比例另外计算。
- 掌握额外超载能力后，本体飞弹伤害系数为0.65，把输出预算转向超载；卸下能力不会绕过该规则。
- 普攻有效命中+2，每秒最多两次；元素命中+2，每2秒一次；有效震荡+8，多目标额外最多+4。震荡催化等级另加命中充能。
- 附近480范围存在敌人时每秒充能2；空放震荡不充能；精英与首领的直接击杀奖励仍为15/30。

## 路线、印记与共享预算

扩张强化覆盖、落点液域与每第三次超载的副环；同化满层奖励锁存，由主技能兑现；
共振保留更短冷却，并使协同伤害额外提高10%、元素反应伤害额外提高15%。

路线资源只消耗一次，液域与印记回响只产生一次。元素印记强化注入和连招反应20%，
深化为30%；不再另外启动一轮晶核反应。元素碎片提供10%注入强化，同系印记合并后不叠加。
液态回流只在实际命中后恢复，仍受独立冷却约束。

主技能、协同、第三技能、元素持续伤害、传导与反应的派生击杀不返还异源能量。
共享令牌限制共振余波与元素反应次数；死亡、结算、重开和换章清理在途连招与任务。

## 元素注入

注入角色由元素等级排名自动派生，不再手动配置；超载不消耗元素等级。
主技能注入第 1 名元素，协同技能注入第 2 名，第三技能（多重超载）注入第 3 名。
同一目标集齐第 1＋2 名元素触发一次主反应连招；再集齐某个副反应组合
（第 3 名与第 1/2 名）触发一次 60% 强度的副反应连招。

| 元素 | 注入效果 |
|---|---|
| 火 | 命中后两次短间隔灼热伤害 |
| 水 | 延长普通敌人的短时缓行；不减速首领 |
| 毒 | 三次较长间隔的持续伤害 |
| 雷 | 向附近目标传导，三级起增加一次传导目标 |

元素等级1～4提高注入效果。每种元素每次超载最多作用于五个不同目标，同一目标不重复叠加同元素注入。
持续伤害由原生执行器结算，不能反过来引发新注入或资源奖励。

| 反应 | 连招效果 |
|---|---|
| 雷涌凝胶（水＋雷） | 受限传导伤害与普通敌人缓行 |
| 爆炸酸液（火＋毒） | 命中位置一次有限范围爆裂 |
| 蒸汽迷雾（火＋水） | 命中位置一次蒸汽缓行，不追加伤害 |
| 爆裂（火＋雷） | 范围溅射，伤害略高于酸液爆裂 |
| 腐蚀（水＋毒） | 范围附加燃烧＋中毒持续伤害 |
| 毒雷风暴（毒＋雷） | 范围中毒持续伤害，概率短麻痹 |

一次超载主/副连招各最多触发一次；第三技能不会重复触发主连招。
没有第 3 名元素或对应副反应未激活时，第三技能退化为注入第 2 名元素。

## 核心掉落

以下稀有掉落规则服务原生黏液，其他角色的既有权限不变。

| 来源 | 规则 |
|---|---|
| 普通怪、普通法师 | 不产出核心 |
| 本局首个有效精英 | 保底一颗 |
| 后续有效精英 | 基础25%；连续四次未掉后下一次保底；成功后清空计数 |
| 召唤精英 | 不产出、不推进或消耗保底 |
| 独立首领、最终首领 | 一颗，提供两种不同属性供选择 |
| 首领编队 | 整队击败后共享一颗二选一核心 |
| 章节守将 | 每章共享一颗预算 |
| 世界事件完成奖励 | 不再直接发核心；其中的有效精英仍按精英规则掉落 |

基础25%不是加入保底后的实际平均掉率。保底跨章节保留、新局重置；重复结算同一敌人不重复发奖。
核心二选一在拾取时暂停，只吸收选择的一种。非法选择与重复提交均被拒绝。

## 验证入口

- `npm run test:origin-combo`：配置、实际双/三技能、单次支付、元素连招、核心保底与二选一。
- `npm run test:origin-combo-browser`：真实Vue桌面/窄屏操作与截图。
- `npm test`：完整回归；`npm run build`：生产构建。
- `node audit-origin-memory.mjs sim 10 1`：固定种子、三路线与对照场景。
- `node audit-origin-memory.mjs sim-combo 10 1`：优先发现协同、学习多重超载、吸收源质后调整主技能的构筑策略。

伤害统计使用实际生命损失，分开主技能、协同、第三技能、元素、反应、路线、印记与余波。
审计自动选择奖励且无敌场景会强制恢复遗漏的演出暂停，结果是可复现的工程对照，不等同于真人通关率。
