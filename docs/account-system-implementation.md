# 统一账号、记录与排行榜

2026-10-15

## 行为

- 游玩需要登录；公开排行榜独立于登录，首页始终可打开。
- 注册自动建立成长档案；已有账号、主战场成长与三槽存档继续可用，槽管理收进账号面板。
- 主战场、突围三模式与塔防均领取账号行动票据并提交幂等结算。塔防关卡、星级、教程与无尽纪录由服务器保存，跨设备恢复；塔防与突围不随主战场存档槽切换。
- 个人历史按账号分页查询；删除成长槽保留已完成行动。公共榜按玩法、模式和难度分开，每账号一条最佳成绩，支持分页与定位自己的排名。
- 塔防战役榜仅列通关成绩，优先比较最高关卡；塔防无尽优先比较波次，再比较分数。
- 断网结算以票据为键逐条暂存，按账号隔离；恢复网络、登录或手动重试可补交，补交窗口三十天。两个标签页使用不同暂存键，成功响应丢失后重试不会重复入账。
- 尚未同步时暂停开新局；永久错误保留具体原因，可明确确认放弃。浏览器无法暂存时提示保持页面打开。
- 旧本机迁移需在账号面板明确确认；主战场替换和塔防最高进度合并在同一事务完成，不把导入数据发布为公共成绩。

## 兼容与运行

SQLite migration v2 为旧数据增加玩法字段，并新增账号游戏数据表；旧 runs 自动归为 arena，不重置已有用户或存档。`npm start` 构建并启动，`npm run serve` 运行已有构建；旧 `lan` 命令和 `createLanApp` 导出保留为兼容入口。

正式服务升级前使用 SQLite backup 创建快照，随后重启 8013 账号服务；开发前端 3013 的 API 代理已确认能读取新版接口。

## 验证

- 全量 `npm test` 通过，覆盖既有角色、战斗、突围和塔防回归。
- 新增 `account-system-test.mjs`：旧库升级、匿名访问限制、账号与玩法隔离、塔防解锁、跨设备恢复、旧档合并、62 名玩家跨页排名、个人历史、删除存档后保留成绩、断线重载、幂等重试、永久错误与暂存失败。
- 浏览器隔离测试账号：未登录可查看并切换榜单，塔防开局要求登录；注册成功后进入战役，实际失败结算显示已保存，并在「我的记录」中出现。刷新可恢复登录。
- 生产构建通过；仍有原有的大体积主包提示，不影响本次功能。

## 范围

局域网继续作为可用部署方式，玩家界面不再提供独立局域网模式。记录与榜单在同一后端内共享。当前校验属于客户端游戏的统计合理性校验，不等同于完整战斗回放验证。
