## 1. 设计目标与核心架构

### 1.1 解决的 6 个核心痛点
1. **路线过于抽象，缺乏职业幻想**：旧版三条路线（元素君临 / 双系融合 / 万象轮转）只是“元素数量分配”，每条仅 2 张纯数值进阶卡；确认单系后甚至会直接废掉前期已抽到的第二、三系，挫败感极强。
2. **只有“平 A 魔杖”，缺少大法术交响曲**：旧版每系只有 1 个基础自动法术（火球 / 冰箭 / 电链 / 毒囊），升级大多在微调同一个技能参数，缺少火焰雨、暴风雪、地狱火、闪电过载、瘟疫传染等标志性循环与洗地技能。
3. **体验断层与遗留缺陷**：
   - 旧单系终极「元素君临」文案写“进入极化状态连续强化”，代码实际仅为单次圆圈爆炸（`SpellCombat.js`）；
   - HUD 路线投入误读 `this.upgrades` 导致始终显示 `0/4`；
   - 路线进阶卡 0 级预览未按 `lv + 1` 计算，显示 `+0%`；
   - 毒系开局 3.4 秒抛一次慢速毒囊手感拖沓，雷系闪电链打孤立首领乏力，冰系对免疫冻结的首领缺少“深冬碎冰”补偿。
4. **脆皮防御同质化**：`-1 生命上限` 的法师全系共用一块无差别法术护盾，缺乏烈焰护体、寒冰护体、闪电之盾、灵魂榨取式的职业防御闭环。
5. **打击感与后期成长不足**：缺少全系重击顿帧（`CombatFeedback`）与无尽模式 Wave 25+ 专属成长卡。
6. **原生黏液与元素史莱姆边界重叠**：两者原先都在玩“元素核心 + 双元素融合反应”，彻底纯化后，原生黏液专攻“异源混搭与元素反应超载”，元素史莱姆专攻“四系法术专精大魔导”。

### 1.2 核心设计支柱
- **四条独立大专精（`fire` / `ice` / `lightning` / `poison`）**：
  - **🔥 烈焰毁灭（火法 × 毁灭术）**：火球术 + 炽热连击（瞬发炎爆） + **火焰雨** + 空格**召唤地狱火** + 烈焰护体。
  - **❄️ 极寒御法（冰霜法师）**：寒冰箭 + 碎冰·寒冰指（冰枪术） + **暴风雪**（刷冷） + 空格**冰霜新星·极寒彗星** + 寒冰护体。
  - **⚡ 雷霆过载（元素萨 × 风暴法师）**：**闪电链**（含孤立单体补偿） + **闪电过载**（复制连劈 + 静电蓄能） + 天罚雷暴 + 空格**风暴守护者** + 闪电之盾。
  - **☠️ 瘟疫灾厄（痛苦术士）**：腐化箭（叠层痛楚） + **瘟疫传染** + 腐蚀之种（毒瘴+种爆） + 空格**灾厄狂欢**（全屏不消 DoT 引爆+刷新） + 灵魂榨取。
- **「Lv.2 定系 + 跨系基础法术书 + 中期本系双分支升华」节奏**：
  1. **Lv.1 开局**：原质飞弹 + 1 点法术护盾 + 空格「原质释放」。
  2. **Lv.2 专精择道（4 选 1）**：复用 `SpellCoreModal.vue` 的 2×2 面板，从 **火 / 冰 / 电 / 毒** 中择一确立本局主专精——**立刻替换主法术、立刻激活本系特色护盾、立刻进化空格为本系招牌主动技**！
  3. **Lv.3 ~ 中期（零稀释成长 + 跨系基础法术书）**：升级池聚焦主系 7 张核心技能卡 + 法术护盾 + 通用生存；同时可低权重抽到另外 3 系的**1 级基础法术卡**（如火法学寒冰箭减速、电法学腐化箭挂易伤），绝不把别系进阶卡塞进卡池。
  4. **第 6 波 / 远征第 3 章（本系秘术升华 · 2 选 1）**：复用 `ElementalRouteChoice.vue`，在本系内二选一锁定高阶流派分支（保留本系全部招牌大法术，只把你偏好的机制推至极致），解锁 2 张分支高阶进阶卡。
  5. **Lv.14 + 第 10 波 / 远征第 5 章 + 投入达标**：随机出现所选分支的**互斥终极卡**。
- **严格遵守全游戏工程红线**：
  - **单主动键契约**：所有技能通过「高频填充 + 触发/循环大法术 + 空格招牌主动 + 特色被动护盾」落地，不新增任何快捷键，完整适配桌面与 390px 触屏。
  - **防递归与性能红线**：过载闪电标记 `overloaded: true` 严禁再触发过载；传染、殉爆、种爆、献祭、冰枪迸裂等派生伤害标记 `derived: true`；地面法术区、地狱火、寒冰宝珠、每帧传染数均设严格硬上限。
  - **视觉可读性红线**：地面领域（火焰雨、暴风雪、毒瘴）绘制于敌人与敌方弹幕下方，采用低饱和度渐变底 + 清晰范围虚线边，绝不遮挡弓手/法师弹幕与 Boss 预警圈。

## 2. 血统底盘、跨系基础法术书与四系特色护盾

### 2.1 基础属性与施法统一公式
保持元素史莱姆「高暴击玻璃大炮」身份（`src/game/Strains.js`）：
- **先天属性**：暴击率 `+8%`，生命上限 `−1`；开局自带 `1` 点法术护盾（破盾后 `8s` 重建）。
- **法术强度与施法急速统一**：
  - `basePower = weapon.damage × weapon.levelMul × spellGenePowerMul × spellGeneRoutePowerMul × (primarySpec === 'elemental' ? 1.2 : 1) × endlessArcaneMul`；
  - `hasteFactor = weapon.attackInterval`（受速射基因、狩猎亢奋、急速类增益驱动）：直接缩放填充技间隔（下限 `0.42s`），并按 `50%` 权重同步缩短自动大法术冷却周期（下限 `2.2s`），让所有急速收益全链路生效。
- **重击打击感（`CombatFeedback`）**：
  - 炎爆术、地狱火陨石、冰霜彗星、冰川尖刺、风暴守护者开场天雷、灾厄狂欢引爆统一按单次爆发合并命中数与击杀数，满足 `hits >= 5 || kills >= 3` 时触发 `35ms` 重击顿帧与 `5px` 镜头微回弹（单体首领重击触发 `16ms` 短顿帧）。

### 2.2 跨系基础法术书（「火法也会寒冰箭」机制）
确立主专精后，**其余 3 系的最基础法术**将以一次性功能卡（`kind: 'cantrip'`，`maxLevel: 1`，权重 `0.38`）进入普通升级池：

| 技能 ID | 名称 | 所属系 | 触发频率 | 核心效果（吃全局法强/暴击/急速，不触发副系专精被动） | 跨系战术价值 |
| --- | --- | --- | --- | --- | --- |
| `cantrip_fire` | **基础：火球术** | 🔥 火 | `2.3s` | 发射 1 颗小火球，命中产生 `54px` 爆炸（`0.95×` 伤）并附加 `2s` 轻度点燃（每跳 `0.15×`）。 | 为冰/电/毒补足小范围溅射与收割补刀。 |
| `cantrip_ice` | **基础：寒冰箭** | ❄️ 冰 | `2.1s` | 射出 1 支穿透 `2` 敌的寒冰箭（`0.80×` 伤），命中减速普通敌人 `35%` 持续 `2.0s`（不叠主系霜纹）。 | 火法/电法/毒术的神级风筝减速工具。 |

**防卡池稀释与博学加成规则**：
1. **单次选卡上限**：每次普通 3 选 1 最多出现 **1 张**跨系基础卡，保证至少 2 张为主系成长或通用生存卡。
2. **学习数量上限**：单局最多兼修 **2 门**跨系基础法术（配置常量 `MAX_CROSS_CANTRIPS = 2`，便于调优）；人物周身呈现「1 枚大主系符文 + 最多 2 枚小副系符文」，HUD 槽位在 390px 移动端依旧整洁。
3. **零进阶污染**：习得跨系基础法术**不会**解锁该系任何进阶/大法术卡，主系卡池保持 100% 纯净。
4. **博学魔导微加成**：每习得 1 门跨系基础法术，主系法术最终伤害额外 `+5%`（上限 `+10%`），确保拿工具技能永远不亏输出节奏。

## 3. 四条专精体系完整技能、升华分支与数值规范

> **统一口径**：
> - 所有卡片 `stats(lv)` 均以 `const next = lv + 1` 计算下一级真实收益，杜绝 `Lv.0` 显示 `+0`。
> - **Lv.3 首选保底**：Lv.2 确立主系后，Lv.3 首次常规升级的 3 个候选中，保底至少出现 1 张本系「招牌引擎卡」或「自动大法术解锁卡」。
> - **第 6 波 / 远征第 3 章秘术升华保底**：选择某升华分支时，若玩家尚未抽到该分支依赖的核心自动大法术（火焰雨 / 暴风雪 / 天罚雷暴 / 腐蚀之种），**升华确认瞬间自动免费授予 Lv.1**；若已持有，则立即获得 `+1` 级免费晋升或直接生效全额升华质变。
> - **互斥终极门槛**：`player.level >= 14` 且 `(wave >= 10 || expeditionStage >= 5)` 且本系路线投入 `>= 4`（计入本系自动大法术 + 空格主动强化 + 分支 2 张进阶卡的总等级）。

## 7. 自动化测试与验收矩阵

重构完成后需同步更新并扩展 `verify-elemental.mjs`、`verify-elemental-build.mjs`、`verify-elemental-icons.mjs` 及全量回归脚本：
